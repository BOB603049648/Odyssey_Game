# Shore clean background

`shore-clean.png` was generated by editing the repository's current `painted/shore-scene.webp` with OpenAI image generation for this prototype. The original generated artifact remains at `/workspace/generated_images/exec-01fb2fe8-5892-434b-9d34-2f480c60f1f3.png` in the working environment.

The gate, mural, driftwood, spring, waystone, direction sign and front rocks were removed and the ground behind them reconstructed. The original painting supplies separately traced upright props; the clean plate supplies the perspective floor and distant scenery. This new image is an art edit, not original unmodified source art.

The current source masks are first-pass silhouettes and need visual refinement. The bottom sand strip is mirrored by the floor material outside the authored image to cover limited camera dolly. This does not author hidden backs or side views of the props.

## Fifth pass

- `shore-props-alpha.png`: registered foreground extraction from the original shore painting. Generated artifact: `exec-c6f4a0a2-ec6c-44da-a8a1-061e4608bf66.png`.
- `hall-clean.png`: original hall painting edited to remove near columns, reading furniture, wrist knot and threshold while reconstructing wood behind them. Generated artifact: `exec-c7aa8f6e-65d8-44e8-8577-c198211239aa.png`.
- `hall-props-alpha.png`: registered hall foreground extraction. Generated artifact: `exec-77117c83-741a-4e28-8dd5-bed501c23b5e.png`.

All three artifacts remain under `/workspace/generated_images/` in this working environment. These edits were made with OpenAI image generation. Extracted RGB is not used in prop color: the original painting supplies RGB, while the new PNG alpha channel supplies coverage for both color and shadow passes. Masks have natural partial edge coverage; the material applies alpha testing and multisample coverage. The masks and scene compositions still need browser visual acceptance.
