## 剩余限制

- 当前只实现序章与东巴岛六场景。海图其他岛屿、最终对峙尚未开放。
- 壁画与复用已有情景识别和相近词干扰项；尚缺需要多次观察、组合线索与改变环境的多步骤谜题。
- 存档保留场景与剧情进度，刷新后人物站位回到场景默认落点；精确站位暂未持久化。
- 人物步态已补入新的三方向四帧图集，属于初版逐帧动画；交互已有四帧伸手、饮水和坐姿休息，站立仍用原有素材，动作衔接还可继续细化。
- 向导站立、等待、蜷卧等叙事状态暂时共用一张完整立绘；跳跃保留。完整到达伸展和分姿势动画仍需美术制作。
- 六个探索场景和词义情景画已统一重绘，六场景配有环境音景；探索环境主体仍是静态 2D 绘景，序章采用局部关节、天气与水面动画。
- 手机浏览器已检查横竖屏布局及触屏移动，未覆盖所有设备。仓库只有 Capacitor 配置，没有 iOS/Android 原生工程。
- 阿里云固定测试站为 `http://47.252.94.138/test/`，以 `version.json` 核对部署提交；仓库修复不等于线上已更新。
