# 语言学习游戏 · 产品说明（草稿）

> 用解谜闯关学真实、远距语言：好玩优先，又能带走真词。正式产品名已定为「奥德赛」，绝不沿用《巴别塔圣歌》名称。

## 一句话定位

工作名已定：**奥德赛**。灵感来自《巴别塔圣歌》的破译乐趣，产品本身不做同名、不蹭其品牌。

一款用游戏闯关学「完全看不懂的真实语言」的学习 App：机制像解谜，内容是真拼写、真读音、真常用义。

## 灵感与问题

> 《巴别塔圣歌》靠观察、猜测、验证破译虚构文字，很有趣；多邻国能真学语言，但不够好玩。我们要叠在一起——学真语言，玩法却要有破译心流。

注意：原作是五层虚构文字解谜，不是「一关一个真实单词」。借鉴的是循环与反馈，不是关卡编号方式或命名。

## 目标用户

| 角色 | 说明 | 优先级 |
|------|------|--------|
| 语言好奇者 | 想碰小众或「完全看不懂」的语言，不为考试，为探索感 | 主用户 |
| 游戏玩家 | 喜欢解谜、闯关、收集进度，愿意为「通关感」反复试错 | 主用户 |
| 轻度学习者 | 被多邻国劝退或觉得无聊，但仍想每天摸几分钟真语言 | 次用户 |

## 核心玩法（待迭代）

方向草案：少给母语翻译，用画面、选项、组合、听音猜义；猜对推进并解锁词库；旧词在后续关复现。

1. 进入一关：目标语字形/语音为主
2. 用轻操作猜义：点选、配对、听音选图等
3. 即时反馈：错可再试，对则入库
4. 复现：旧词嵌进新关，类似间隔复习

## 和多邻国差在哪

**我们要赢的点**

- 游戏感优先：解谜心流，而不是「今日课时」
- 陌生感优先：远距语言 + 少翻译
- 复现像闯关：旧词嵌进新关，而不是单独刷闪卡

**我们故意不做的**

- 不先做完整语法树、考试路径、职场场景包
- 不做成开放聊天陪练
- 不承诺「三十天流利」，只承诺好玩地记住一批真词
