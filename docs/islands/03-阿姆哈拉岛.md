# 阿姆哈拉岛设计

> 《奥德赛》第三岛：碑铭文明、阿姆哈拉语与吉兹系 Fidel 文字；故事、词表、罪证、向导奈奈茶可执行。

## 岛定位

| 项 | 内容 |
|----|------|
| 语言 | 阿姆哈拉语 Amharic（埃塞俄比亚）；吉兹系 Fidel 音节字母 |
| 风格 | 碑铭文明 · 石城、经堂、市集 |
| 表层目标 | 借船或换东航文书；读懂门楣与契约 |
| 梯度位置 | 从声野部落进入「有城有经」的人世高峰 |

**本岛主轴：** 玩的是认字与契约：Fidel 字符块可点、可拼；罪证是经卷点名「断语者」与你签过的城约。

## 完整故事线

1. **开局** — 旱航抵达石港。满墙圆角字母；市集喧闹但你一个字都不识。船工要看「通行符」才肯修桅。
2. **存活主线** — 要饮水配额、客栈铺位、工料。告示全是 Fidel：认错符会领到罚单或空碗。
3. **关键冲突** — 城门契约：外乡人须在石板上拼对「求助或交易」短句。祭司指控有人曾毁约断航；城内排外与互助两派拉你站边。
4. **罪证事件** — 经堂禁卷：学到足够字后可读残页，点名断语者；另一页有你的签押影。写入案卷第三枚碎片。
5. **向导登场** — 奈奈茶以墨黑形态守在经堂阶前；教 Fidel 基本拼合的是港口通事，他不说破你是谁，但劝你读完禁卷再走。
6. **离岛** — 拼对东航许可句，得冰海航线残图；预告「字像冰块一样拼起来」的北方。

## 视觉与壁画

- 地貌：玄武岩城、梯田绿、经堂烛火、红土市集
- 文字墙：Fidel 字符作装饰与谜题；圆角、疏密如碑
- 壁画：圣徒式叙事带+契约双手印；比部落壁画更「工整描金」
- 对比塔阿：从赭石鼓圈变为石刻与墨色经卷

## 语言特色进玩法

1. **字符拼盘** — Fidel 音节块拖到槽位组成词；听 NPC 读音高亮对应块
2. **门楣认读** — 进店前选对门楣词（水、粮、客）才开门
3. **契约板** — 短句填空：主体+给予+对象；错则板裂重来
4. **不考语法树** — 只教生存与契约高频；词义仍靠场面+字符形对照

## 罪证钩子

- 经卷点名断语者（学够字才可读）
- 城约残页上有与玩家相同的签押习惯
- 祭司低语：毁约之人会忘自己的名——呼应失忆
- 可漏禁卷仍可离岛

## 向导与离岛

向导：奈奈茶引路；教学 NPC 是港口通事。离岛提示由通事说：再往东，字会变成冰上的几何块；有人在北方用字画你的脸。通事交给你东航文书，奈奈茶叼来残图新角。

## 主线细化

> 与 [主线剧本与世界观](../05-主线剧本与世界观.md) 对齐。本岛是断语路线的中段：他在城约档案上落签押、蜡封中枢副本，城邦从此失去法律记忆（城邦失忆）。

### 场景清单

| 场景 | 作用 | 关键交互 |
|------|------|----------|
| 石港 | 靠岸；船工要通行符 | 门楣认读 |
| 市集 | 饮水配额、口粮、排外派与互助派 | 多摊位字牌；领错得空碗或罚单 |
| 客栈 | 铺位 | 门楣「客」 |
| 档案馆 | 老法官；封存的中枢副本 | 3-A 证物；重建城约 |
| 废弃渡语人行会 | 画像 | 3-B 证物 |
| 经堂 | 祭司、铜钟（旧中继）、禁卷 | 3-M 主证物 |
| 城门 | 契约板关卡 | 拼对「求助或交易」短句 |

### 奈奈茶在本岛

| 项 | 内容 |
|----|------|
| 形态 | 墨黑、胸前一块白，颈下挂一枚铜片，纹样像 Fidel 字符，端坐如石狮；旧绳圈不变 |
| 引路 | 守在经堂阶前；城里人多，她走屋脊 |
| 提示 | 字符拼盘里她用爪尖点正确的元音形；契约板上她卧在缺词的槽位旁 |
| 情感点 | 行会画像里那只系绳圈的小猫，与她脖子上的绳圈一模一样 |

### 关键 NPC

| NPC | 做什么 | 教什么 |
|-----|--------|--------|
| 港口通事（教学 NPC） | 教 Fidel 拼合；不说破你是谁；劝你读完禁卷再走 | 读、写、字符块 |
| 船工 | 要看通行符才修桅 | 船、门、开 |
| 经堂祭司 | 指控有人毁约断航；「毁约之人会忘自己的名」 | 罪或咎、誓言 |
| 档案馆老法官 | 记不起自己判过的法；请你帮他从石板原件重建一条城约 | 契约、违约、宽恕 |
| 排外派首领 | 要求外乡人一律交押金 | 拒绝（跨岛预告） |
| 互助派首领 | 给外乡人赊粮，但要立约 | 给、求 |

### 节拍细化

1. **靠岸** — 满墙 Fidel。船工指着门楣不让进；学会「门、开」并选对门楣后进入港口。
2. **市集生存** — 认错字牌领到空碗。通事在摊边教第一组字符块（同一辅音配不同元音形），玩家第一次完成拼词。
3. **两派拉扯** — 排外派与互助派各给一个任务。选哪派不影响主线通关，只影响结局 B 后记卡的城邦画面。
4. **档案馆** — 老法官的城约原件只有石板，他读不全。帮他拼出一条「给予」条款，档案库深处露出蜡封门，触发 3-A「封存档案」。
5. **行会大厅** — 奈奈茶领你走进废弃的渡语人行会，在一幅群像前坐下。群像里一人脸被刮花，腕上通约结与你相同；他脚边蹲着一只系绳圈的小茶猫（3-B「行会画像」）。你回头看她，她把脸转开了。
6. **城门契约** — 外乡人须在石板上拼对「我 + 求 + 通行」。错则板裂重来。
7. **禁卷** — 字符层达标后，祭司允许你读禁卷残页：点名「断语者」，附签押，与档案门上的签押同形（3-M「断语者之名」）。
8. **离岛** — 拼对东航许可句，得冰海残图；通事说「北方有人用字画你的脸」。离岛时触发回忆：他用通约结在小猫脖子上系了一截旧绳。

### 语言特色补充（需核对）

- Fidel 是元音附标型音节文字：同一辅音基字通过附加笔画表示不同元音。字符拼盘按「基字 → 元音形」两步教学，每次只开放一个辅音家族。
- 参考词（须经顾问核对后才可实装）：水 ውሃ、门 በር、火 እሳት、人 ሰው、船 መርከብ、石 ድንጋይ。

### 罪证与向导伏笔

- 3-A 和 3-M 的签押是同一个通约结变体，提醒玩家这个结在第一岛背叛墙上见过，也系在奈奈茶脖子上。
- 3-B 是奈奈茶与主角旧关系的第一处实证。本岛离岛回忆（系绳圈）紧跟在 3-B 之后，让玩家把画像里的小猫和身边的大猫连起来。

## 验收清单

- 门楣与契约板不靠母语可过
- 至少一次 Fidel 拼词
- 禁卷罪证可发现可漏
- 离岛预告因纽特几何字
