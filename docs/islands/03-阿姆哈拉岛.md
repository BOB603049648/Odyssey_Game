# 阿姆哈拉岛设计

> 《奥德赛》第三岛：碑铭文明、阿姆哈拉语与吉兹系 Fidel 文字；故事、词表、罪证、向导可执行。

## 岛定位

| 项 | 内容 |
|----|------|
| 语言 | 阿姆哈拉语 Amharic（埃塞俄比亚）；吉兹系 Fidel 音节字母 |
| 风格 | 碑铭文明 · 石城、经堂、市集 |
| 表层目标 | 借船或换东航文书；读懂门楣与契约 |
| 梯度位置 | 从声野部落进入「有城有经」的人世高峰 |

**本岛主轴：** 玩的是认字与契约：Fidel 字符块可点、可拼；罪证是经卷点名「断语者」与你签过的城约。

## 完整故事线

1. **开局** — 旱航抵达石港。满墙圆角字母；市集喧闹但你一个字都不识。船工要看「通行符」才肯修桅。
2. **存活主线** — 要饮水配额、客栈铺位、工料。告示全是 Fidel：认错符会领到罚单或空碗。
3. **关键冲突** — 城门契约：外乡人须在石板上拼对「求助或交易」短句。祭司指控有人曾毁约断航；城内排外与互助两派拉你站边。
4. **罪证事件** — 经堂禁卷：学到足够字后可读残页，点名断语者；另一页有你的签押影。写入案卷第三枚碎片。
5. **向导登场** — 抄经人或港口通事：教 Fidel 基本拼合；不说破你是谁，但劝你读完禁卷再走。
6. **离岛** — 拼对东航许可句，得冰海航线残图；预告「字像冰块一样拼起来」的北方。

## 视觉与壁画

- 地貌：玄武岩城、梯田绿、经堂烛火、红土市集
- 文字墙：Fidel 字符作装饰与谜题；圆角、疏密如碑
- 壁画：圣徒式叙事带+契约双手印；比部落壁画更「工整描金」
- 对比塔阿：从赭石鼓圈变为石刻与墨色经卷

## 语言特色进玩法

1. **字符拼盘** — Fidel 音节块拖到槽位组成词；听 NPC 读音高亮对应块
2. **门楣认读** — 进店前选对门楣词（水、粮、客）才开门
3. **契约板** — 短句填空：主体+给予+对象；错则板裂重来
4. **不考语法树** — 只教生存与契约高频；词义仍靠场面+字符形对照

## 罪证钩子

- 经卷点名断语者（学够字才可读）
- 城约残页上有与玩家相同的签押习惯
- 祭司低语：毁约之人会忘自己的名——呼应失忆
- 可漏禁卷仍可离岛

## 向导与离岛

向导：港口通事。离岛提示：再往东，字会变成冰上的几何块；有人在北方用字画你的脸。交给你东航文书与残图新角。

## 验收清单

- 门楣与契约板不靠母语可过
- 至少一次 Fidel 拼词
- 禁卷罪证可发现可漏
- 离岛预告因纽特几何字
