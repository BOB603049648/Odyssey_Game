# 因纽特岛设计

> 《奥德赛》第四岛：北极疏离、因纽特语音节文字与多式综合；通缉罪证、词表与向导奈奈茶可执行。

## 岛定位

| 项 | 内容 |
|----|------|
| 语言 | 因纽特语 Inuktitut；加拿大原住民音节文字；多式综合 |
| 风格 | 几何疏离 · 冰原、雪屋、极光、石标 |
| 表层目标 | 拼出航图、避风暴、通过哨站 |
| 梯度位置 | 字形如模块 UI，语法如长编码，垫向赛博巴斯克 |

## 完整故事线

1. **开局** — 破冰船式木舟靠上白岸。风声大过人声。路标是几何音节块；认错方向会冻伤（游戏内回检查点）。
2. **存活主线** — 要暖棚、油脂灯、干粮。交易靠拼「我要热或吃」的长词模块。
3. **关键冲突** — 哨站封锁：风暴将至，只放「名字干净」的人通过。墙上开始贴音节通缉——画像轮廓越来越像你。
4. **罪证事件** — 拼齐通缉令全文：罪名与断语相关；人脸补全为玩家。强制或半强制写入第四枚案卷碎片。
5. **向导登场** — 奈奈茶以雪白形态在冰原上引路；教音节拼合与长词积木的是破冰领航，他说「东边那座城里，机器用另一种孤立的话审判人」。
6. **离岛** — 用正确长词通过哨站；残图几乎拼满；航向赛博港。

## 视觉与壁画

- 地貌：冰裂、极夜或极昼、石堆路标、兽皮暖棚
- 文字：音节块如黑白瓷砖，可旋转拼接
- 壁画：简直线刻+极光色带；少人情、多方位与天气
- 对比阿姆哈拉：从暖石经堂到冷几何模块

## 语言特色进玩法

1. **音节积木** — 拖拽音节块拼词；正确块吸附发光
2. **多式综合长词** — 词根+方向+时态模块像编程拼装；教 3 到 5 种高频模板即可
3. **方位生存** — 绝对方位词影响地图箭头；学错则导航翻转
4. **听感** — 长词整段播放，波形与音节块同步高亮

## 罪证钩子

- 音节通缉令画像渐变成玩家
- 罪名行用已学模块可译：与断语、禁声、毁约相关
- 节奏：本岛起否认变难，为第五岛摊牌铺路
- 若跳过译文直接冲哨站，仍可走但案卷缺页

## 向导与离岛

向导：奈奈茶引路；教学 NPC 是破冰领航。离岛提示由领航说：尽头那座城里，话很少人情；机器会用巴斯克语问你是谁——最好先想起自己。奈奈茶叼来最后一角，双生残图几乎完整。

## 主线细化

> 与 [主线剧本与世界观](../05-主线剧本与世界观.md) 对齐。本岛是断语路线的第二站：他注销了风暴石标里的名字（包括他自己的），风暴预警中断，猎人未归。

### 场景清单

| 场景 | 作用 | 关键交互 |
|------|------|----------|
| 白岸 | 靠岸；几何音节路标 | 认错方向回检查点 |
| 暖棚 | 油脂灯、干粮 | 长词模板「我要暖」 |
| 风暴石标 | 旧中继，沉默 | 4-A 证物前置 |
| 雪屋 | 老妇讲风暴夜 | 4-A 证物 |
| 哨站 | 通缉墙；开杆 | 4-M 主证物；长词模板「我往东走」 |
| 冰缘 | 离岛 | 残图几乎拼满 |

### 奈奈茶在本岛

| 项 | 内容 |
|----|------|
| 形态 | 雪白长毛，毛间结着冰晶，比雪豹还大；旧绳圈不变 |
| 引路 | 在白茫茫里，她是唯一的方向；方位读错时她停在原地不动，等他回来 |
| 提示 | 音节积木里她用鼻尖顶一下需要旋转的块；长词模板里她依次看向缺的模块 |
| 情感点 | 孩子问他名字、他答不上来时，她走过来把头抵在他手心 |

### 关键 NPC

| NPC | 做什么 | 教什么 |
|-----|--------|--------|
| 破冰领航（教学 NPC） | 教音节旋转与长词积木；说「东边那座城里，机器用另一种孤立的话审判人」 | 东、西、归航 |
| 哨站长 | 风暴将至，只放「名字干净」的人过 | 通行、名字、通缉 |
| 随亡者取名的孩子 | 名字来自风暴里没回来的猎人；问你叫什么 | 名字、我与你 |
| 雪屋老妇 | 讲风暴那夜石标没有喊人 | 风暴、孤独、危险 |

### 节拍细化

1. **白岸** — 风声大过人声。路标是音节块，方向读错会冻伤并回检查点（只扣时间，不扣进度）。
2. **暖棚** — 学「火或灯、暖」，用长词模板一「我要暖」换到油脂灯。
3. **石标** — 风暴石标沉默。领航用手势说它以前会「喊人回家」。奈奈茶绕着石标走了一圈，没有停。
4. **雪屋** — 老妇讲风暴夜，玩家用已学词拼出她的叙述（风暴、走、海、危险），触发 4-A「没响的石标」。
5. **孩子的名字** — 孩子问你的名字，你答不上来。名字层达标后，她把一块旧名牌给你：上面的名字被整行划掉，看不清（4-B「划掉的名字」）。
6. **哨站封锁** — 通缉墙上的音节画像一天比一天像你。用长词模块逐行译完通缉令，脸补全（4-M「通缉令全文」）。
7. **通过哨站** — 用模板二「我往东走」通过。如果跳过译文直接冲哨站，也能通过，但案卷缺页。
8. **离岛** — 领航说「机器会问你是谁——最好先想起自己」；奈奈茶叼来最后一角残图。离岛时触发回忆：他蹲下叫小猫的名字，声音被一阵静电盖住。本岛主题是「名字」：他想不起自己的，也想不起她的。

### 语言特色补充（需核对）

- 音节文字中同一形状旋转方向代表不同元音（如 ᐃ i / ᐅ u / ᐊ a，ᐱ pi / ᐳ pu / ᐸ pa）。积木「旋转」就是换元音，正好做成核心手感。
- 多式综合长词只教 3–5 个高频模板，模块颜色固定：词根、方向、人称、时态。
- 参考词（须核对）：人 ᐃᓄᒃ inuk、屋 ᐃᒡᓗ iglu、冰 ᓯᑯ siku、海 ᑕᕆᐅᖅ tariuq、狗 ᕿᒻᒥᖅ qimmiq、油脂灯 ᖁᓪᓕᖅ qulliq、名字 ᐊᑎᖅ atiq。
- 命名传统题材敏感：4-B 与孩子支线的台词上线前须请文化顾问审读。

### 罪证节奏

本岛是「否认变难」的转折：4-M 强制或半强制。玩家第一次在案卷里看到自己的脸被写上罪名。

## 验收清单

- 至少两套长词模板能过交易与哨站
- 音节拼合不靠母语
- 通缉罪证可见可部分跳过
- 离岛指向赛博巴斯克
