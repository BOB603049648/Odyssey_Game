# 塔阿岛设计

> 《奥德赛》第二岛：南部非洲部落、塔阿语搭嘴音；故事线、词表、听辨玩法、罪证与向导。

## 岛定位

| 项 | 内容 |
|----|------|
| 语言 | 塔阿语 Taa（!Xóõ），南部非洲 |
| 风格 | 野性声景 · 旱谷红岩鼓圈 |
| 表层目标 | 求水、求通行、换东航绳结 |
| 梯度位置 | 比皮拉罕多一层听辨野性 |

## 完整故事线

1. **开局** — 旱湾靠岸；搭嘴音如石子碰撞；模仿对一记短声符才有人理你。
2. **存活主线** — 阴凉岩棚、饮水、兽肉份额；不会声符只看着水囊。
3. **关键冲突** — 哑声禁忌：外乡人长时间只做口型被视为不祥；白天交易必须发对声符。
4. **罪证事件** — 圣岩壁画轮廓与玩家重合；忌讳故事写外来哑声曾断航线；案卷第二枚碎片。
5. **向导登场** — 鼓圈边缘中间人；教听辨；暗示你以前来过这种安静。
6. **离岛** — 通行声符换东航绳结；预告碑铭城（阿姆哈拉）。

## 视觉与壁画

- 旱谷、刺树、红岩棚、热浪
- 赭石壁画+声纹符波浪线
- 对比皮拉罕：雨林潮线变鼓圈旱地

## 语言特色进玩法

- 听辨：点选匹配声纹符；最小对立对
- 鼓点节奏点按视为发音
- 口型剪影辅助；开麦仅可选彩蛋非硬门
- 沉默过久关闭交易

## 罪证钩子

哑声禁忌即主冲突；圣岩轮廓重合；碎片闪回禁止发声或断互通。可漏。

## 向导与离岛

向导：鼓圈中间人。离岛：东边把话刻在墙上的城；你的安静比鼓更可怕。绳结+残图角。

## 主线细化

> 与 [主线剧本与世界观](../05-主线剧本与世界观.md) 对齐。本岛对应断语路线的倒数第二站：他在圣岩前无声下令，鼓声航标熄灭；向导汐在这里翻译到一半被切断，并被他留下。

### 场景清单

| 场景 | 作用 | 关键交互 |
|------|------|----------|
| 旱湾 | 靠岸；第一次模仿声符 | 口型剪影 + 声纹符点选 |
| 红岩棚 | 阴凉与过夜 | 对棚主说对「给」才能进 |
| 水窖 | 生存门槛 | 白天交易：声符错或沉默过久即关闭 |
| 鼓圈 | 向导所在；回声石 | 节奏点按；2-B 证物 |
| 圣岩 | 鼓座（旧中继）；禁忌壁画 | 2-M 主证物 |
| 失航者小屋 | 受害者后代支线 | 2-A 证物 |

### 关键 NPC

| NPC | 做什么 | 教什么 |
|-----|--------|--------|
| 向导（汐的化身：鼓圈中间人） | 教听辨；哼第一岛那段旋律；暗示「你以前来过这种安静」 | 听、说、通行 |
| 鼓长 | 守圣岩；最怀疑「哑声外来者」；裁决你能否通行 | 禁忌、敲、鼓 |
| 水窖看守 | 按声符给水 | 水、喝、清浊对 |
| 失航者之女 | 父亲的船在鼓声熄灭后没回来；一直在修一面旧鼓 | 等待（跨岛复现）、背叛 |
| 鼓圈孩子 | 用搭嘴音玩「你说我指」的游戏 | 搭嘴唇 / 搭嘴齿最小对立对 |

### 节拍细化

1. **靠岸** — 没人理会只做口型的外来者。模仿对第一个短声符后，孩子回头看你：完成第一次听辨。
2. **要水** — 水窖看守只认声符。玩家听不清就只能看着水囊，计时条走完交易关闭，可重试。
3. **哑声禁忌** — 玩家沉默太久被鼓长当众驱离，学到「禁忌」。向导在鼓圈边把你领回来，说明白天交易必须发对声符。
4. **回声石** — 鼓圈中央有一块旧回声石，听辨层齐后能听到 2-B「中断的译声」：一个女声翻译到一半变成静音。（这正是汐的声音，此时不点破。）
5. **失航者支线** — 帮老妇修鼓：按节奏敲出「承诺」与「等待」。修好后她讲起熄灭那一夜，交出旧鼓槌残片，触发 2-A「拿走的鼓槌」。
6. **圣岩** — 鼓长允许你读圣岩，前提是在鼓圈当众「说」对通行声符。读完禁忌壁画触发 2-M「哑声指令」，外来者的轮廓与你重合。
7. **离岛** — 向导用通行声符换到东航绳结，说「你的安静比鼓更可怕」；低语补「……一座岛一座岛，」。

### 语言特色补充（需核对）

- 塔阿语以辅音数量极多著称，搭嘴音有多个发音部位。教学只取 2–3 组最小对立，不追求覆盖全部。
- 声纹符是游戏内的视觉化辅助，不能冒充正式转写。词库中真实转写与声纹符并列显示。

### 罪证与向导伏笔

- 2-B 的女声在第五岛摊牌时以原声回放，玩家应能认出是向导。
- 鼓长对向导也有戒心：「她也是外来的，但她肯学。」这一句为「学，而不是让机器替你说」的主题铺垫。
