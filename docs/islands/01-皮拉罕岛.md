# 皮拉罕岛设计

> 《奥德赛》第一岛：亚马孙部落、皮拉罕语；完整故事线、词表、壁画教学、罪证与向导。

## 岛定位

| 项 | 内容 |
|----|------|
| 语言 | 皮拉罕语 Pirahã（巴西亚马孙） |
| 风格 | 原始部落 · 雨林河岸 |
| 表层目标 | 活命：水、食物、过夜；再得东航提示 |
| 梯度位置 | 五岛最「野」：无数词感、即时经验、指物教学 |

## 完整故事线

1. **开局** — 风暴翻船冲上岸；听得见音听不懂义；夹一句想不起的母语低语。
2. **存活主线** — 要水、食物、过夜处；每步靠猜词与指物推进。
3. **关键冲突** — 生存误会：拿错份额、走近危险岸；靠学分享、危险、给等词化解，不战斗。
4. **罪证事件** — 潮线或背叛墙多笔；点中腕纹或「断」手势闪回，写入案卷（可漏）。
5. **向导登场** — 懂外来者手势；多看你半秒；教往东并给残图。
6. **离岛** — 残图亮一角，航向塔阿旱岛。

## 视觉与壁画

- 地貌：潮线、棚火、渔获、密林
- 壁画：矿物线刻，日月水火鱼人母题
- 抽象词：多格叙事，不画孤立符号

详见 [壁画视觉词典](../04-壁画视觉词典-皮拉罕.md)。

## 语言特色进玩法

- 无数精确数：只用多与少相对量
- 零母语字幕；壁画+实物对照入库
- 层锁：具体到动作到关系到抽象；缺词格模糊

## 罪证钩子

背叛墙纹身与主角相同；潮线「断」手势碎片；向导旧层可读才掉主碎片。可漏不卡关。

## 向导与离岛

向导：知情不报。离岛提示：往东走，每座岛话不同；残图一角。预告旱地鼓声之岛。

## 验收清单

- 不靠母语完成存活与至少10词
- 抽象层依赖具体词
- 罪证可漏
- 离岛指向塔阿
