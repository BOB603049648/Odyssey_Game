# 皮拉罕岛设计

> 《奥德赛》第一岛：亚马孙部落、皮拉罕语；完整故事线、词表、壁画教学、罪证与向导奈奈茶。

## 岛定位

| 项 | 内容 |
|----|------|
| 语言 | 皮拉罕语 Pirahã（巴西亚马孙） |
| 风格 | 原始部落 · 雨林河岸 |
| 表层目标 | 活命：水、食物、过夜；再得东航提示 |
| 梯度位置 | 五岛最「野」：无数词感、即时经验、指物教学 |

## 完整故事线

1. **开局** — 风暴翻船冲上岸；听得见音听不懂义；黑暗里一声猫叫。
2. **存活主线** — 要水、食物、过夜处；每步靠猜词与指物推进。
3. **关键冲突** — 生存误会：拿错份额、走近危险岸；靠学分享、危险、给等词化解，不战斗。
4. **罪证事件** — 潮线或背叛墙多笔；点中腕纹或「断」手势闪回，写入案卷（可漏）。
5. **向导登场** — 比人还大的猫咪精灵奈奈茶（此时玩家不知道她的名字）；回头多看你半秒；领你往东，把残图叼到你脚边。
6. **离岛** — 残图亮一角，航向塔阿旱岛。

## 视觉与壁画

- 地貌：潮线、棚火、渔获、密林
- 壁画：矿物线刻，日月水火鱼人母题
- 抽象词：多格叙事，不画孤立符号

详见 [壁画视觉词典](../04-壁画视觉词典-皮拉罕.md)。

## 语言特色进玩法

- 无数精确数：只用多与少相对量
- 零母语字幕；壁画+实物对照入库
- 层锁：具体到动作到关系到抽象；缺词格模糊

## 罪证钩子

背叛墙纹身与主角相同；潮线「断」手势碎片；奈奈茶夜里守着的旧层可读才掉主碎片。可漏不卡关。

## 向导与离岛

向导：奈奈茶，不说话，只引路和提示。离岛提示由老人用手势和壁画给出：往东走，每座岛话不同。奈奈茶叼来残图一角。预告旱地鼓声之岛。

## 主线细化

> 与 [主线剧本与世界观](../05-主线剧本与世界观.md) 对齐。本岛对应主角断语路线的**最后一站**：他在潮线鸣石前做出「断」的手势，然后走进风暴。

### 场景清单

| 场景 | 作用 | 关键交互 |
|------|------|----------|
| 潮线 | 开局、序章证物、离岛码头 | 裂开的鸣石；漂木堆（奈奈茶先领你到这里；不止一条旧船残骸） |
| 棚火营地 | 存活主线枢纽：过夜、分食 | 对 NPC 做动作验证（吃/喝/睡/给/拿） |
| 河湾渔场 | 份额冲突 | 多/少相对量；剖鱼「分享」 |
| 壁画岩 | 视觉词典主墙、背叛墙、等待墙、旧层 | 核格点选，见壁画视觉词典 |
| 密林边界 | 危险教学 | 止步姿态；兽影 |
| 夜营 | 奈奈茶夜里伏在旧层前不走；主证物 | 抽象层读完才可读 |

### 奈奈茶在本岛

| 项 | 内容 |
|----|------|
| 形态 | 雨林斑纹、茶色打底，耳后别一片宽叶，豹一般大；脖子上一截旧绳圈 |
| 初见 | 远远伏在潮线上看他，不靠近；等他站起来才起身走在前面 |
| 引路 | 走到下一个目标附近坐下，回头等他 |
| 提示 | 三级提示（看 / 走 / 拍）第一次在「要水」节拍教给玩家：玩家卡住时她转头望向水囊 |
| 暗号 | 绳圈上的结与背叛墙取物者腕上的结同形（玩家学会「背叛」后才可能注意到） |

### 关键 NPC

| NPC | 做什么 | 教什么 |
|-----|--------|--------|
| 模仿手势的孩子（教学 NPC） | 跟着你做动作，第一个对你笑；偶尔朝奈奈茶的方向看一眼 | 我、你、给，动作词 |
| 夜看壁画的老人（教学 NPC） | 带你读壁画；记得「说数字的石头」和那年的饥荒 | 等待、饥饿；主证物前置 |
| 渔人兄弟 | 为一条鱼的分法争执，误会你偷拿 | 分享、多与少、拿 |

### 节拍细化

1. **序章** — 风暴黑屏，一声猫叫。冲上潮线后第一个可点物是裂开的鸣石；点它触发 1-A「签署手势」，教会玩家打开案卷。
2. **初见** — 潮线远处伏着一只比人还大的猫。她领你到漂木堆前坐了一会儿（那里有不止一条旧船的残骸），然后起身朝营地走，回头等你。
3. **要水** — 孩子从河边捧水回来；壁画主墙「水」核格亮起。玩家点壁画再点水囊入库，完成第一次「指物」。卡住时奈奈茶转头看水囊：第一次提示。
4. **要吃** — 渔人兄弟在剖鱼。玩家拿错半边被推开；去壁画学「分享」后再对兄弟做「给」，冲突化解。
5. **要睡** — 棚火边学「火、睡」，孩子把位置让出来。奈奈茶在火光外蜷着，发出那种让他心安的呼噜声。
6. **危险** — 夜里想跟着奈奈茶进密林，被老人拦下；学会「危险」后止步，才能改走河岸。奈奈茶在林边停下，等他绕路。
7. **抽象层开放** — 关系词齐后苔藓剥落，露出背叛墙与等待墙；学会「背叛」可点出 1-B「绳结纹身」。
8. **旧层** — 奈奈茶夜里伏在旧层前不走。老人陪你读：读完饥饿、承诺、危险等抽象格后，旧层画面完整，掉落 1-M「数字的石头」。
9. **离岛** — 老人用手势和壁画指东；奈奈茶把残图一角叼到你脚边，回头看你半秒。离岛时触发回忆：雨夜，码头木板下一只湿透的小猫。

### 语言特色补充（需核对）

- 皮拉罕语有声调，据记录可以哼唱或吹口哨传达。老人的哼唱可做成「声调轮廓线」教学提示。
- 岛民只关心眼前经验，没人问主角从哪来；这与第五岛核验塔的第一问形成对照。演出要克制，不把有争议的语言学结论讲成定论。

### 受害者后代支线

老人那一代被中继「翻译」出来的精确数字判为欠货。陪他看完等待墙的日轮印串，他会把一枚刻有计数符号的旧鱼骨交给你。鱼骨只作物件，不进案卷，但能让 1-M 的画面多出一格（被搬走的渔获）。

### 漂木堆

漂木堆里有不止一条旧船的残骸。奈奈茶会先领他到那里坐一会儿。这是环境叙事：断语之后海上有过失船。不拾成额外证物，也不是新周目线索。

## 验收清单

- 不靠母语完成存活与至少10词
- 抽象层依赖具体词
- 罪证可漏
- 离岛指向塔阿
- 奈奈茶三级提示（看 / 走 / 拍）都能触发，且不出现任何母语文字
