# 皮拉罕岛设计

> 《奥德赛》第一岛：亚马孙部落、皮拉罕语；完整故事线、词表、壁画教学、罪证与向导。

## 岛定位

| 项 | 内容 |
|----|------|
| 语言 | 皮拉罕语 Pirahã（巴西亚马孙） |
| 风格 | 原始部落 · 雨林河岸 |
| 表层目标 | 活命：水、食物、过夜；再得东航提示 |
| 梯度位置 | 五岛最「野」：无数词感、即时经验、指物教学 |

## 完整故事线

1. **开局** — 风暴翻船冲上岸；听得见音听不懂义；夹一句想不起的母语低语。
2. **存活主线** — 要水、食物、过夜处；每步靠猜词与指物推进。
3. **关键冲突** — 生存误会：拿错份额、走近危险岸；靠学分享、危险、给等词化解，不战斗。
4. **罪证事件** — 潮线或背叛墙多笔；点中腕纹或「断」手势闪回，写入案卷（可漏）。
5. **向导登场** — 懂外来者手势；多看你半秒；教往东并给残图。
6. **离岛** — 残图亮一角，航向塔阿旱岛。

## 视觉与壁画

- 地貌：潮线、棚火、渔获、密林
- 壁画：矿物线刻，日月水火鱼人母题
- 抽象词：多格叙事，不画孤立符号

详见 [壁画视觉词典](../04-壁画视觉词典-皮拉罕.md)。

## 语言特色进玩法

- 无数精确数：只用多与少相对量
- 零母语字幕；壁画+实物对照入库
- 层锁：具体到动作到关系到抽象；缺词格模糊

## 罪证钩子

背叛墙纹身与主角相同；潮线「断」手势碎片；向导旧层可读才掉主碎片。可漏不卡关。

## 向导与离岛

向导：知情不报。离岛提示：往东走，每座岛话不同；残图一角。预告旱地鼓声之岛。

## 主线细化

> 与 [主线剧本与世界观](../05-主线剧本与世界观.md) 对齐。本岛对应主角断语路线的**最后一站**：他在潮线鸣石前做出「断」的手势，然后走进风暴。

### 场景清单

| 场景 | 作用 | 关键交互 |
|------|------|----------|
| 潮线 | 开局、序章证物、离岛码头 | 裂开的鸣石；漂木堆（周目线索） |
| 棚火营地 | 存活主线枢纽：过夜、分食 | 对 NPC 做动作验证（吃/喝/睡/给/拿） |
| 河湾渔场 | 份额冲突 | 多/少相对量；剖鱼「分享」 |
| 壁画岩 | 视觉词典主墙、背叛墙、等待墙、旧层 | 核格点选，见壁画视觉词典 |
| 密林边界 | 危险教学 | 止步姿态；兽影 |
| 夜营 | 向导夜看旧层；主证物 | 抽象层读完才可读 |

### 关键 NPC

| NPC | 做什么 | 教什么 |
|-----|--------|--------|
| 向导（汐的化身：林边的外来女人） | 不替你翻译，只用手势和实物示范 | 往东；残图 |
| 模仿手势的孩子 | 跟着你做动作，第一个对你笑 | 我、你、给 |
| 渔人兄弟 | 为一条鱼的分法争执，误会你偷拿 | 分享、多与少、拿 |
| 夜看壁画的老人 | 记得「说数字的石头」和那年的饥荒 | 等待、饥饿；主证物前置 |

### 节拍细化

1. **序章** — 风暴黑屏，低语「如果你又被浪送回来——」。冲上潮线后第一个可点物是裂开的鸣石；点它触发 1-A「签署手势」，教会玩家打开案卷。
2. **要水** — 孩子从河边捧水回来；壁画主墙「水」核格亮起。玩家点壁画再点水囊入库，完成第一次「指物」。
3. **要吃** — 渔人兄弟在剖鱼。玩家拿错半边被推开；去壁画学「分享」后再对兄弟做「给」，冲突化解。
4. **要睡** — 棚火边学「火、睡」，孩子把位置让出来。
5. **危险** — 夜里想去密林找向导，被老人拦下；学会「危险」后止步，才能改走河岸。
6. **抽象层开放** — 关系词齐后苔藓剥落，露出背叛墙与等待墙；学会「背叛」可点出 1-B「绳结纹身」。
7. **旧层** — 向导夜里坐在旧层前哼一段旋律。读完饥饿、承诺、危险等抽象格后，旧层画面完整，掉落 1-M「数字的石头」。
8. **离岛** — 向导递残图，说出离岛提示；低语补「……别找机器，」。

### 语言特色补充（需核对）

- 皮拉罕语有声调，据记录可以哼唱或吹口哨传达。向导的哼唱旋律可做成「声调轮廓线」提示，同一段旋律在后续四岛反复出现，作为向导身份暗号。
- 岛民只关心眼前经验，没人问主角从哪来；这与第五岛核验塔的第一问形成对照。演出要克制，不把有争议的语言学结论讲成定论。

### 受害者后代支线

老人那一代被回声「翻译」出来的精确数字判为欠货。陪他看完等待墙的日轮印串，他会把一枚刻有计数符号的旧鱼骨交给你。鱼骨只作物件，不进案卷，但能让 1-M 的画面多出一格（被搬走的渔获）。

### 周目细节

漂木堆里有刻着通约结的旧船板：一周目不可拾取，新周目可拾为第 16 枚证物「上一次」。
