# 巴斯克赛博岛设计

> 《奥德赛》第五岛终局：赛博都市、巴斯克语孤立语；日志摊牌、语言对峙 Boss、词表与分支结局。

## 岛定位

| 项 | 内容 |
|----|------|
| 语言 | 巴斯克语 Basque（欧洲孤立语）；作格等结构疏离 |
| 风格 | 赛博都市 · 霓虹、栈桥港、双语全息、雨 |
| 表层目标 | 读懂回家坐标；通过系统核验 |
| 梯度位置 | 五岛终点：非人疏离的现代，Boss 是完整的你 |

**终局岛：** 学词仍在，但每学一批，系统日志就多一行「欢迎回来」。向导在此摊牌。

## 完整故事线

1. **开局** — 破浪进入霓虹港。广告巴斯克语滚动；义体安检要你用当地语报身份——你报母语被拒。
2. **存活主线** — 要能量票、干宿舱、码头许可。自动机只认巴斯克短句模板。
3. **关键冲突** — 核验塔：须用巴斯克语回答「你是谁、从哪来、要去哪」。错三次触发镜像层（预 Boss）。城内有人认你是救星，有人认你是灾因。
4. **罪证事件** — 中枢日志：最后登录者是你；断语协议由你签署。向导摊牌。案卷第五枚与此前碎片拼成完整罪证。
5. **向导登场** — 正是一路若隐若现的向导（或其一贯化身）：交出真相，逼你选择承认或逃避。
6. **离岛或终局** — 无传统离岛：语言对峙「完整的你」。通关分支见下；真结局可启航回家或留下缝合航线。

## 视觉与界面

- 地貌：雨港、磁浮轨、全息告示、黑玻璃中枢
- 文字：拉丁字母巴斯克语；UI 风对照因纽特音节的「更冷」
- 壁画变成全息广告与日志瀑布；罪证是可滚的终端
- 对比前岛：从冰原石标到赛博栈桥

## 语言特色进玩法

1. **作格直觉** — 用颜色标「谁受影响」：作格句里施事与对象槽位对调教学，不讲术语
2. **孤立语疏离** — 广告词与欧洲邻语都不像；强调「听着像欧洲却对不上」
3. **终端填槽** — 核验句拖词入槽；与前岛积木手感统一
4. **Boss 对峙** — 调出五岛词库答题：翻译旧命令、反驳断语协议

## 罪证钩子与 Boss

- 系统日志最后登录者是你
- 向导摊牌：你一路学语，是在回收自己拆掉的钥匙
- Boss：完整断语者人格（镜像或中枢投影）
- 对峙：用五岛真词翻译或反驳旧命令；答错重播案卷
- 分支：碎片少假归乡；齐+承认留下缝合；齐+重来开周目

## 向导与结局

向导于此撕破温情面具（仍可慈悲）。结局不「再航向第六岛」，而是坐标抉择：逃、留、或再忘。新周目可保留部分词库作未忘干净。

## 主线细化

> 与 [主线剧本与世界观](../05-主线剧本与世界观.md) 对齐。本岛是灯港，中枢「回声」所在，也是断语路线的起点：他在这里登录并签署断语协议。城名、中枢名为中文工作名，主角真名待定；三者都不取自巴斯克语词。

### 节拍细化

1. **入港** — 安检要求用当地语报身份；玩家用母语回答被拒，被引向自动机学最短的自我介绍。
2. **生存** — 学「进、付、开」，用短句换能量票与宿舱。宿舱旧终端里有一段录音，需结构层达标后才能听懂：5-B「留给自己的录音」。
3. **两种期待** — 复响派把你当救星，带你看档案柜。读懂草案即得 5-A「统一语令」（动机）。老船匠在工坊里说的话，是同一问题的另一面。
4. **核验塔** — 三问：Nor zara zu?（你是谁？）Nondik zatoz?（你从哪来？）Nora zoaz?（你要去哪？）。第一次只能浅答，例如「我往家去」；错三次触发镜像层，Boss 第一次露面后又消失。
5. **中枢日志** — 通过核验后进入中枢。日志末行：通译体【真名】登录并签署断语协议（5-M「最后登录」）。主角第一次听到自己的名字。
6. **摊牌** — 系统管理员摘下工牌：就是一路的向导。她当面说完整句低语，并回放 2-B 中断的译声：「那是我。」
7. **镜厅** — 五回合语言对峙，规则见主线剧本第七节。
8. **抉择** — 承认或否认，留下、回家或遗忘，对应三结局。

### 作格教学细化（需核对）

- 色标规则：施事（带 -k 的作格）一色，受影响者（通格）一色；色盲模式另加形状标记。
- 示例句（须核对）：Gizonak ura edan du（那个人喝了水）。对比不及物句 Gizona etorri da（那个人来了），让玩家自己发现「同一个人，句子不同，词尾不同」。
- 参考词（须核对）：水 ura、雨 euria、门 atea、灯 argi、进 sartu、付 ordaindu、开 ireki、关 itxi、我 ni、你 zu、城 hiri、真相 egia、家 etxe、留下 geratu、遗忘 ahaztu、承认 onartu、否认 ukatu。

### 结局分支速查

| 结局 | 条件 |
|------|------|
| A 假归乡 | 碎片少，或第 5 回合选否认 |
| B 新渡语人 | 碎片齐 + 承认 + 留下 |
| C 再忘 | 碎片齐 + 承认 + 遗忘 → 新周目 |

## 验收清单

- 核验塔短句不靠母语可过
- 作格槽位教学可感
- 日志罪证与向导摊牌必达
- Boss 调用至少三岛词库
- 三个结局分支可达成
