## 0. 一句话定位

**电影感 2D 探索解谜**：你在岛上**控制一名旅人**走动、走近物与人；用学到的「字义」活下去，并拼出自己曾切断诸岛语言的罪证。向导奈奈茶不说话、不教词，只用身体给提示。

不是：Duolingo 卡片课、PPT 切图、FPS。

## 2. 推荐方案（默认按此讨论）

### 2.1 视角

- **第三人称、略俯斜的 2D 全屏场景**（类似电影截图里的「人站在景里」）。
- **镜头跟随旅人**：人走，画面轻跟；边界到场景边缘时停。
- **禁止**：第一人称准星、自由飞行相机、纯 UI 全屏卡片当主画面。

### 2.2 玩家主体

- 屏幕上永远有一个**可辨认的旅人精灵**（占位可先剪影/低模；正式立绘后补）。
- **不是奈奈茶**。奈奈茶是同伴 NPC，可走近、可被提示系统驱动。
- 体型参考：人远小于戴兜大猫，强化「被引领」感。

### 2.3 操作

| 输入 | 行为 |
|------|------|
| WASD / 方向键 | 在可行走带内移动 |
| 鼠标左键点地面 | 自动寻路走到该点（与键控并存） |
| 走近可交互物 + 再点 / E | 打开交互（壁画配对、取水、案卷等） |
| Esc / 案卷按钮 | 打开案卷 / 词库（半透明叠层，不切走场景） |

移动只发生在**可行走带**（岸线、小径）；越界有软阻挡（轻推回 / 脚步声停）。

### 2.4 核心循环（一岛）

```
探索走动 → 发现物/壁画 → 用已有词或配对学会新义
    → 用词推进存活/通行 → 偶然撞上罪证钩子
    → 奈奈茶三级提示（看→走→拍）在卡住时介入
    → 离岛条件满足 → 短过场 → 下一岛
```

教学不靠弹出「正确答案」大字，靠**场景验证**（点对水囊才解渴；配对壁画才解锁路障）。

### 2.5 奈奈茶在循环里的位置

- 默认在场景内 AI 闲逛/跟随（距离环），不挡路。
- L1 看：头转向目标；L2 走到目标旁；L3 拍热区。
- 颈结：案卷有对应绳结证物时 `glow`。
- 回忆段切**小猫**剪影/立绘，主线回戴兜大猫。

### 2.6 HUD（diegetic）

- 顶栏：稀薄玻璃条（进度/岛名可极淡）。
- 热区：平时几乎只有光点，走近或悬停才出短标签。
- **不在画面写「奈奈茶」**；词义中文开关默认关。

### 2.7 MVP 验收（第一岛可玩）

1. 能用键或点地在潮线/营地之间走动，看到自己的旅人。
2. 必须走近才能交互，不能「隔空点图标切图」。
3. 至少完成：学若干词 → 一次存活验证 → 一次壁画配对 → 见一次奈奈茶提示。
4. 电影感光影与半透明 HUD 保留；禁止回到纯幻灯片。

## 4. 场景与内容结构（开发对齐）

- 一岛 = 若干**可连续走动的场景图**（或一张大图+相机窗），场景间用路口/叠化过渡，**不要**「点菜单跳幻灯」。
- 内容仍 JSON（词条、热区、节拍）；热区带世界坐标 + 交互半径。
- 现有「点热区切文案」逻辑改为：**半径内才可交互**。
