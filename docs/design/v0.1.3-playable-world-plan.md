# v0.1.3：东巴岛的操作、表演与持续变化

本轮只深化已有首章：两段环境谜题、人物与向导动作衔接、操作后的场景变化。继续使用现有六场景、28 字和四项生存目标。玩家应能从画面看懂自己拿了什么、做了什么、世界因此发生了什么。

## 一、雾岸取水：空瓢到清泉

| 阶段 | 玩家操作 | 可见结果与反馈 |
| --- | --- | --- |
| 空瓢 | 观察泉池边的瓢，走近拿起 | 原画中的瓢消失；旅人伸手，显示手中是空瓢 |
| 寻水 | 可走向潮水或泉嘴 | 潮水反馈咸涩，杯和进度保留；泉嘴的流水与石壁水纹呼应 |
| 接水 | 已理解“水”后，在泉嘴接水 | 伸手与水声同步，手中状态变成清水；不会立即完成饮水目标 |
| 饮用 | 喝下接到的清水 | 饮水动作、吞咽与放杯同步；瓢归位，饮水目标完成 |

玩法以场景物件为入口，不添加一轮含义选择题。第一段只要求理解“水”，不额外强制解锁整层动作词。取错水、提前喝水、重复接水均可恢复；没有死亡、资源损失或永久错误。阶段跨场景、刷新和导入存档保留。

## 二、前坪分食：亲手留下一半

| 阶段 | 玩家操作 | 可见结果与反馈 |
| --- | --- | --- |
| 观察 | 查看粮篮和两份餐食的位置 | 看清四份食物，以及自己和同行者的两只碗 |
| 拿取 | 从篮中取出食物 | 原篮变空，四份食物进入分配近景 |
| 分配 | 点击一只碗，把一份食物移过去；也可移回 | 4/0、3/1、2/2 等分布由真实食物图显示，食物总量始终为四份 |
| 递交 | 理解“分享／给予”后，将均分的餐食递出 | 旅人递交，向导回应；右侧碗留下两份餐食，分食目标完成 |

近景是一张与场景同画风的双碗操作面，不用文字答案列表。分配不均时说明哪一份未准备好，允许继续调配。关闭近景、回壁画学习或中途离开均不清空分配。完成后的重复互动不复制食物、不重复奖励。

## 三、人物与向导表演

- 保留已经验证的位移步态、统一图片比例和脚点；起停过渡不增加假位移，不通过缩放全身表现呼吸。
- 旅人互动统一为进入、接触、收势。面对物件后再拿取／饮水；补站到坐的中间姿势，起身使用对应过渡。移动始终可打断互动。
- 修正现有菜单暂停仍消耗动作时间的问题：菜单、后台和场景加载共用暂停规则，恢复后继续当前动作。
- 向导增加独立观察、抬爪、坐下和蜷卧素材；到达后先落稳，再进入静态表演。等待、求助、分食、休息的姿态应可区分。
- 新素材尚未解码或加载失败时保留完整已就绪角色；不显示透明空帧，不改变主体比例。减少动态效果时保留有含义的稳定姿势。

## 四、持续场景反馈

以 `puzzleState(save)` 为唯一玩法阶段来源，`worldState(save)` 只投影视觉状态，不复制第二套进度。

- 雾岸：瓢被拿起后原位为空；饮用后归位，泉嘴与池内有局部流水／水纹。
- 前坪：拿取后源篮为空；分食完成后右侧碗留有两份。背景使用以原图为参考生成的局部状态贴片，保持透视、照明和物件位置。
- 棚火／夜营：局部火光与余烬活动；经堂：局部窗光尘埃。效果位于背景与角色之间，不遮挡交互，不扩大可走区域。
- 返回场景、刷新与导入存档后直接呈现保存结果，不重演奖励动画。菜单、后台和减少动态效果停止装饰运动。

## 实施分工与边界

1. 玩法 agent：纯状态转换、错误操作约束、旧存档兼容、目标与提示、核心规则测试。
2. 动画 agent：角色时间线、朝向、坐起与向导素材、暂停和加载回退、动作测试。
3. 场景 agent：视觉状态投影、局部贴片、环境动效与状态测试。
4. 主 agent：素材风格检查、场景热点和近景操作接线、交互文案、声音联动、完整浏览器验收与发布。

存档版本保持 2；已完成的 `dba.beat.water`、`dba.beat.food` 优先于新阶段，老玩家无需重做。旧版若正停在雾岸的选水字弹层，按已拿起杯子继续，选对后接满，仍需饮用才完成。新操作在核心层校验所在场景、界面与阶段，不能仅靠按钮隐藏防止越过步骤。

## 验收门槛

- 新存档完成两段谜题，再完成休息、避险、离岛与首章结尾；旧完成存档直接继续。
- 错水源、空瓢饮用、提前递交、分配不均、跨场景调用均不错误完成目标；总食物量不变。
- 每个中间步骤保存、刷新、恢复后继续；快速连点不复制奖励。
- 四向走停、转身互动、连续动作、菜单暂停、后台返回、移动打断没有放大、脚点漂移或迟到声音。
- 桌面鼠标／键盘和手机触屏都能完成；减少动态效果保留阶段可读性。
- 完整背景与局部贴片没有重叠道具或矩形接缝；慢加载不使角色和操作入口消失。
- 通过规则、组件、内容校验、生产构建和真实浏览器主线检查后，再推送并交给 Grok 部署 `/test/`。
