# 第八轮：聚落人物、口述与异抄

2026-11-16。沿用第一岛的山水聚落与绘画材质，加入四位可交谈的人物；不改变奈奈茶以动作引路的身份。

| 人物 | 出现场景 | 提供的经历 |
| --- | --- | --- |
| 巡路匠 | 雾岸、雾径 | 水渠上下游与山路退路；担忧与现场事实要分开 |
| 守火人 | 棚火 | “客可息”与“客当守”怎样改变来客的处境 |
| 分食渔人 | 前坪 | 数量记录、共食记录与偿还条件的区别 |
| 抄卷人 | 经堂、夜营 | 字形和读音的功能、口传与书写、墨层先后与责任归属 |

四位 NPC 是游戏虚构人物，服装采用一致的旧布、朴素灰蓝与褐色、麻绳和纸册，并非特定族群服饰的史料复原。角色 atlas 使用图像生成工具一次生成，保持四人的比例、笔触与光向一致。来源见 `src/assets/art/npc/README.md`。

## 对话与提示

走近人物后点击人物的交谈区域，或使用既有 E / 附近交互控件。远处点击先寻路至身旁，不在同一个脚点重叠；仍需靠近后再次交互。对话为原生 modal，暂停玩家移动并保持关闭、键盘焦点和 Esc 行为。

可问眼前见闻、旧事回忆、核对方法。方法分两步，不自动填写释读或证据，不授予词义、证物或通关节拍。对话会区分当前页尚未读懂、前页未完成与当前页已核读的情况。跨过阅读顺序不能提前取得后页的细节；已经请求过的口述保存到手记与案卷，并明确标为口述，不作为系统认证的事实。

对话为可选帮助，旧存档直接可用，不增加通关门槛。六道题原有的旁证选择仍保留，未改成必须搜集全部场景证据的玩法。

## 题目呈现与难度

新增原页与异抄并读：雾岸的渠上旁记、棚火的铺边改抄、前坪的偿还补语、雾径的缺字残注。比较的内容涉及具体人的处境：水流留给谁、谁得以休息、共同用餐怎样被改成欠债、暂停危险后如何照顾同行者。

六题的干扰项改为看似可成立但需要额外前提的解释；减少“永远不能”“全都作废”式容易猜中的绝对表达。最后一页仍区分文本改写、身份和动机，避免凭腕纹定罪。答错反馈和第二层提示指向核对方法，保留独立选择解释与两条证据的环节。

汉文原页、异抄、村民回忆均为原创游戏叙事；经堂两个真实字例及资料出处保留原样，不把原创情节当作东巴经文译文。第一章完成页移除提前出现的奈奈茶名字，保留认名伏笔。

生产构建通过；27 个文件的 217 项专项检查经寻路测试等待条件修正后通过。覆盖远处不能隔空交谈、实际寻路至身旁、对话时停止移动、分级提示、记录与存档恢复、未来页保护、完整阅读及生存通关、原有操作和角色动画、空间人物与交谈区域。寻路测试按到达条件等待，不再假定固定帧数足够走完。
