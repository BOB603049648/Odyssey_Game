# 第十轮：界面与交互

2026-11-16。沿用“留与归”的绘画世界，以墨绿、暖纸、旧铜组织界面。视觉样式集中在 `src/ui/interface.css`，限定于 `.odyssey-ui`，不改变场景坐标、人物动画、题目判断或存档格式。

## 当前实现

- 标题页改为左侧构图：章节、题名、上次停留与主要操作分层。有存档时突出继续；新旅程仍保留覆盖确认。声音设置单独展开，保留教学义开关和备份入口。
- HUD 使用统一线条图标和文字，行程说明可折叠；窄屏／低高度视口初始收起长说明，保留目标标题与残卷入口。窄屏菜单保留按钮的可访问名称与 44px 点击尺寸。
- 残卷采用纸页与推理区的双栏布局，手机转为单栏。六页页签区分当前、已读与未到达；显示真实核读进度。释读、旁证分步标示，明确反馈选择数量、满额禁选、可提交和结果状态。保留原文、异抄、馆藏署名、提示与可选练习。
- NPC 对话加入统一标题、人物区、回答区、话题选中与已记录状态。手机保留缩小的人物肖像。文本一次完整显示，切换回答仅作短淡入，不采用拖慢阅读的逐字输出。
- 案卷、字典、设置接入原生 `dialog.showModal()`，共享标题与关闭按钮。浏览器负责模态焦点约束；打开时焦点进入标题，Esc 走 native cancel，点击／按键不传播到场景。旧环境保留可用回退并恢复触发按钮焦点。
- 案卷与字典、音量与存档、分食与断桥、可选刻符练习及加载界面统一边框、排版、按钮和反馈。动作区域继续使用原有游戏逻辑与暂停机制。
- 支持触屏、短屏滚动与 `prefers-reduced-motion`。交互变化主要使用边框、颜色和短淡入；不在场景点击目标上添加改变投影坐标的装饰位移。
