# 连续开场 · 第十三轮

序幕改成约 31 秒的自动连续演出：风暴落水（7.6 秒）→ 伸手救猫（7.6 秒）→ 断语记忆（8.4 秒）→ 潮线醒来（7.4 秒）。播放结束直接进入可操作的雾岸。移除上一幕、下一幕、页码、连播开关和整段旁白面板；空格改为暂停／继续。保留声音开关、从头重看和跳过。

画面占据整个舞台，字幕浮在画面上，每次只出现一句。现有横／竖幅绘画继续提供构图，使用实时镜头推拉、角色局部关节形变、水面位移、风雨、符文裂光与晨雾组成连续演出。此轮不增加视频下载，也没有新绘制完整逐帧角色动作；不能把这版描述成新制作的全角色动画影片。

镜头从人物伸手方向推进，救猫时靠近奈奈茶，记忆推进长卷，醒来时缓慢拉开空间。约 1.1 秒的溶接保留上一镜头的原有 DOM、相机、天气和关节姿态，不切回未变形的静态图。溶接、镜头、字幕与剧情推进共享有效播放时间；暂停时不使用墙钟移除旧画面，隐藏标签页和等待新画面解码均不消耗剧情时间。环境音在镜头之间交叠淡入淡出；暂停和重播及时停音。字幕保留猫、长卷裂痕和熟悉的手三条叙事线索。

标题页新增“重看开场”。它使用独立的演出状态，播完或点击“返回标题”回到标题页，完全不写入冒险存档。真正的新游戏仍完成原有序幕故事状态、首次证据和同行者相遇，再进入雾岸；跳过走相同剧情状态转换，重复观看不重复证据。旧存档继续可用。记忆段开始预取登陆资产，已有轻量预览与高清渐进替换保留。

验证：10 个文件、79 项针对性测试通过；TypeScript 与 Vite 生产构建通过。覆盖完整自动登陆、字幕逐句出现、暂停与后台冻结、悬挂帧不快进、慢加载恢复、溶接中暂停、自动推进防重复、重播证据幂等、标题重看不写存档、声音衔接、减少动态效果以及镜头轨迹中的主体和边界保护。浏览器脚本已迁移序幕入口并通过语法检查；剧情后段原有记忆翻页测试保留。

本环境没有可用的受支持浏览器控制工具，未运行本轮浏览器画面、手机触控或帧率验收；没有将旧截图作为新版证明。实际画面观感仍须在试玩地址验收。可玩范围仍为序幕与第一岛，保留第十一轮原创文字玩法和第十二轮雾岸镜头／行走修正。
