# 画面与人物统一 · 第十五轮

六个可玩场景采用同一套美术基准：灰青阴影、赭金日光、旧木与亚麻的哑光厚涂。保留雾岸、棚火、前坪、经堂、雾径、夜营的地域连续性，也保留日光、窗光、火光、月光的区别。背景构图和上一轮前景素材沿用，统一其饱和度范围与角色环境曝光。

## 人物素材

以现有村民和场景为绘画参考，使用图片生成模型重新绘制主角与奈奈茶的实际运行素材，共七张图集/单图：主角六帧站立、二十四帧行走、十二帧动作、八帧坐下/起身，奈奈茶单图、八帧表演、两帧跳跃。主角保留金发、长旅行衣、手杖和皮包；奈奈茶保留蓝眼睛、重点色面部和兜帽。改变的是笔触、布料与皮肤质感，降低摄影式微细节和塑料高光。

四位 NPC 的原画本来已是这一画风，是本轮的风格参考；不冒称重新绘制了四人。NPC、主角、奈奈茶现在共用环境光和身高体系，且新旧动作不会混用。站立也使用完整图集，不再走旧图的衣摆/脚底像素修补。

模型生成原始 PNG 保存在 `docs/assets/actors-v15/`。运行文件只做 WebP Q95 编码，不用程序重绘、涂抹或生成笔触。打包验证完整 alpha 逐像素一致，并记录不透明区域 RGB 误差。新旧画布差异通过源图测量与运行时裁样处理，不逐帧拉伸肢体。

## 同一人物在不同场景的尺寸

`src/content/sceneScale.ts` 是唯一比例表。数值为逻辑画面的名义人物框高，直立身体占其中约 88%；屏幕实际高度还经过现有相机投影。

| 场景 | 主角名义框高 | 参照物 |
| --- | ---: | --- |
| 雾岸 | .136 | 门楼净高、泉眼盆沿、近岸地面 |
| 棚火 | .158 | 棚门、铺位、火塘坐面 |
| 前坪 | .180 | 门洞、台阶、分食器皿 |
| 经堂 | .220 | 木柱、阅卷架、门槛 |
| 雾径 | .150 | 桥面、护栏、入口石阶 |
| 夜营 | .175 | 亭柱、石案、火塘 |

NPC 的相对身高为主角的 91%–98%，不再由“经堂或其他地方”两档决定。奈奈茶直立参考高度为主角的 40%，所有场景一致；坐卧动作自然变矮，不放大到站立高度。此表是根据绘画参照物校准的美术比例，不是对原画宣称真实建筑测绘。

雾岸迎接位置向浮木前侧移 .04 个逻辑高度，避免合理大小的猫被浮木完全挡住；目标、对白与剧情条件保持原来含义。

## 动作与光照

按实际源图记录每帧脚底和身体轴；同一行走方向共用固定倍率，保留步态起伏。站立、行走、伸手、坐下等不同图集的留白不会改变人物体格。两帧过渡在同一脚点上混合，颜色和阴影共用相同的裁样、倍率和透明度。保留原来的距离驱动步频、八帧步态、暂停和转身过渡。

所有 Three.js 人物贴图上传时预乘透明度，采样后还原颜色再做 sRGB 解码，避免透明边界中的隐藏 RGB 污染轮廓。动画图集仍关闭 mipmap，防止相邻帧串色。新原画不再叠旧版服装压暗滤镜。

雾岸和经堂的立体舞台现在复制人物环境光，不再显示未染色的明亮人物。其他四景使用同一照明函数；夜景人物接受冷月光，靠近火塘时补暖光。DOM 后备画面共用环境曝光，Three.js 额外提供位置相关的窗光/火光。角色身体始终保持源图不透明度，不用半透明淡出“融入背景”。

## 验证边界

184 项检查、30 个测试文件及生产构建通过，覆盖比例、源图注册、动作过渡、采样、场景可达性、连续开场、图集原子加载、原生图片错误与断网重试。结果见本轮 `artifacts/three-v15/verification.json`。

七张运行图共 2,706,248 字节，对应的旧角色素材共 7,578,818 字节；完整 alpha 保持一致。标题启动 JS 的本地 gzip 口径比上一轮增加 1,225 字节。文件体积统计不代表用户网络耗时或帧率实测。

检查了六景素材放置诊断图，以及由实际 Three.js 几何导出的雾岸、经堂离线结构图。诊断图没有浏览器 UI；离线结构图也没有相同的 Three.js 后期与采样器，不能替代游戏截图。本环境仍没有受支持的浏览器控制工具，未完成浏览器视觉、手机触控与帧率验收。
