# 第九轮：试玩加载优化

2026-11-16，基于第八轮聚落对话版，更新原有私有试玩站点。

## 改动与体积

- 标题／序章保留即时入口，岛屿 UI 与可选刻符练习拆为按需下载。标题启动 JS 依赖总计由 900,991 字节降至约 399,972 字节；本地 gzip 合计从 279,728 降至约 130,400 字节，减少约 53%。统计包含入口及其静态依赖、入口显式加载的 App；不把整个 dist 当作首屏下载量。
- 七张运行时 PNG 改为无损 WebP：两处空间底图、两处道具透明图、NPC 图集、主角动作图集、猫的站立图。总计从 9,911,792 降至 6,966,286 字节（减少 29.7%）。其中雾岸涉及的五张图从 6,398,855 降至 4,290,470 字节（减少 33.0%）；这五张不等同于雾岸全部资源。
- 保留源 PNG。逐像素验证宽高、完整 alpha、所有 alpha 大于零的 RGBA 一致；完全透明像素下的隐藏 RGB 可被编码器归零。没有缩图或修改构图、帧数、裁样、脚点、阴影和文化字例。
- 相邻场景不再在第一帧同时发起多个纹理下载和 GPU 上传。当前场景就绪后等待 2 秒，在空闲时逐张低优先级预取；前台纹理仍在加载、玩法暂停或页面在后台时继续让路。离开场景会停止后续排队请求，已经发出的单张请求可完成。显式省流、2G/3G 或报告下行低于 1.5 Mbps 时跳过预取；当前场景的必要请求不受影响。
- HTML 自带轻量加载文字，避免 JavaScript 下载期间空白。异步界面加载失败时提供重新加载；原有图片重试、二维后备显示和本地存档机制继续使用。

## 验证

生产构建通过。121 项相关检查覆盖 18 个文件：标题／继续旅程、图片超时与恢复、首次场景就绪、低优先级预取、异步页面失败、实际移动、NPC、透明图几何与阅读流程。

首次回归有 5 项旧 App 用例失败。用第八轮 App 复测，确认其中 4 项的用例与既有第七／八轮玩法不符：仍假定点石碑直接进刻符题、学会几个符号即可完成旧层。用例已按“残卷 → 创作说明 → 可选练习”更新；旧离岛存档用例明确关闭新路线标记。剩余 1 项改为等待按需加载的岛屿出现。复测通过，没有为满足旧断言回退实际玩法。

构建报告：`artifacts/three-v9/payload-before.json`、`payload-after.json`、`image-compression.json`。复现统计：`node scripts/loading-budget.mjs dist <report.json>`。复现转码与像素校验：`python scripts/encode-loading-assets.py`（需要 ffmpeg、Pillow、numpy）。

这些是构建产物体积，不是用户网络上的下载时间；gzip 仅为本地统一口径，并不宣称服务器实际采用该编码。当前托管环境缺少规定的 `cua_repl.js`，未做浏览器网络瀑布、LCP、GPU 或手机实机验收。没有把旧截图作为本版验证结果。
