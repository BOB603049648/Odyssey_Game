# v0.1.5 学习与探索衔接

目标：让刻符成为解决眼前问题的线索，让玩家反复经历「观察 → 理解 → 操作 → 场景反馈」，减少一次刷完所有题目的感觉。保留六个场景、既有解锁条件和存档。

## 本轮实现

### 石壁知道玩家正在解决什么

石壁上方显示当前旅程需要处理的问题，以及一枚目前可学习的刻符。点刻符只负责切换壁画带、选中题目，仍由玩家观察情景画作答。答错不会获得刻符，也不推进主线。

学到当前所需知识后，显示「回到旅途」，即使该壁画带尚未全部完成，也能返回进入石壁前的场景。玩家仍可继续读其他刻痕、切换已开放的层或进入复用带。

推荐流程遵循原来的层级和前置知识，不绕过锁定、不自动传送、不自动操作物件：

| 阶段 | 推荐的交替过程 | 按推荐顺序累计学字数 |
| --- | --- | --- |
| 饮水 | 拿起空瓢 → 辨认水纹 → 接泉水 → 饮用 | 1 |
| 休息 | 补齐生活中的具体刻痕 → 辨认休息 → 棚火歇息 | 7 |
| 分食 | 观察粮篮、拿取、移动两碗份数 → 补齐相关动作／关系，理解分享 → 递出晚餐 | 16 |
| 避险 | 运用已经理解的危险，在断桥前停步 | 16 |
| 离岛 | 理解饥饿与承诺 → 返回雾岸明确选择离岛 | 18 |

18 个字是这条推荐路径的结果，并非新的通关数量要求。原有通关规则没有变化；其余 10 个字、证物和复用仍可以自由探索。提前完成某项经历、先学其他字、旧存档或已离岛时，建议依据当前实际进度重算。

### 词库保留学字时的情景

已学刻符可点选，展示对应情景画、描述及「已记下／已熟悉」状态。未知刻符不提前公开；教学义开关仍控制中文释义，默认以画面回忆含义。图片暂时不可用时保留情景文字。复用成功仍通过原有玩法获得熟悉状态。

桌面将刻符与画面并排；手机将情景放在上方，刻符排列在下方，可滚动查阅，横竖屏都保留关闭入口。

### 自动帮助更克制

可操作画面中实际闲置 20 秒才自动给一次一级观察提示，不再随着时间自动升级到带路、指出答案。更深入帮助保留给主动求助，且遵守该场景原有帮助上限。

实际移动、按键、触屏按住和滚动都会影响闲置判定。方向键碰壁或长按摇杆也视为玩家正在操作；菜单、分食近景、场景加载、失焦与后台不计时。恢复可操作状态后重新给足 20 秒。活动时间只留在内存，不逐帧写存档。

## 验收

- 新存档先取瓢，只学水即可离开石壁并完成饮水；学习到休息时能从尚未读完的动作层返回。
- 建议的刻符总满足现有解锁和知识前置条件；错选情景不推进；选推荐不自动答题。
- 实际走路、分食、停步、离岛全部通过公开操作完成，18 字推荐路径抵达首章完成页；刷新保留完成进度。
- 词库切换情景、熟悉状态、未知词隐藏、教学义开关和图片失败回退正确。手机触屏可作答、返回、查词和旋屏关闭。
- 持续操作时不误触自动提示；真正闲置后只出现一级；主动求助仍可升级到该场景允许的级别。
- 单元与交互测试：`npm test`；生产构建：`npm run build`；真实 Chromium：启动 preview 后运行 `npm run test:learning`。脚本产出桌面／触屏截图和检查报告。

## 下一轮优先方案（尚未实现）

1. **把刻符用于场景推理。** 先做一段可独立验收的断桥谜题：观察旧桥状态、组合「危险／等待／同行」表达意图，同行者以动作回应，再解锁安全的返回行动。错误理解应引发可恢复的尝试和不同反馈；正确答案由环境事实支持。相应重审整层刷字的门槛，减少为开下一层而学习无关词。验收重点是玩家能解释选择的原因，而非只沿高亮点击。
2. **增加走停和转身过渡。** 为现有同一人物制作每方向八帧步态与短转身，统一脚点、体积和光向；以位移驱动步相，停步收脚，转向先转身体再改变方向。沿用已有碰撞、寻路与落脚音，不重新引入图集缩放闪帧。验收包含快速反向、连续点击、低帧率、暂停及手机录像逐帧检查。
3. **缩短常用交互的操作链。** 普通观察和拿取支持点物件后走近执行，并有目标标记；任何改向或新目标立即取消旧意图。离岛、提交晚餐等推进剧情的动作仍清楚显示将发生什么并由玩家明确触发。镜头和伙伴视线提前响应目标，行动后留下可见变化。验收包含到达前取消、目标失效、换场景、开菜单与旧交互不会迟到执行。

这一轮改善学习节奏与查阅体验，角色行走仍是原有三方向四帧。后续评价应分别看可读性、操作响应、推理空间和人物表演，不能仅以素材数量或自动化通关代替实际游玩感受。
