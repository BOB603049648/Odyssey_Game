# v0.1.4 行走与场景切换

目标：玩家能判断脚下可走范围、确认目的地，并理解什么时候换场景。保留现有六个场景和主线，沿用存档。

## 玩家操作

- 打开右下角「路线」会停步并显示浅金色可走区域。点击「固定地面引导」可在关闭面板后保留区域提示。
- 选择出口后显示剩余实际路径与目的地，绕开障碍，到达路口内侧后沿箭头方向出门。
- 键盘、摇杆、其他地面点击可以改变路线；互动会停步。暂停菜单冻结导航，恢复后继续。
- 点击海水、墙面、桌案或桥外会停止并说明原因。只容许约三个原画像素的边缘误差，不把远处非法点击投影成合法目的地。
- 出口小标签显示方向与目的地；靠近后出现换场提示。普通场景往返不以谜题完成为条件；离岛仍需完成主线并明确互动。

## 实现约束

碰撞、点击判定与地面提示共同使用 `plantOnGround` / `onGround`。提示轮廓由同一判定生成并按场景缓存，保留障碍孔洞；边缘向内保守取样，避免把桥外标成可走。路线保留寻路拐点，不用平滑曲线切穿障碍。

每个出口是有宽度和方向的门线。检测本次位移是否从内向外穿过口宽范围，即使一步跨过整个触发深度也有效。平行、反向或口外跨线不切场。自动导航先到内侧接近点，再走过门线，避免从旁边靠近导致停在出口之外。

夜营寻路与碰撞共享桌案、火塘占地数据。旋转屏幕时世界尺寸与镜头偏移同步更新，暂停中也保持画面覆盖视口、人物在画面内。导航、对白在视口内堆叠；地面和路径在世界坐标内跟随镜头，不能拦截点击。

## 验收

单元测试覆盖六场景地面轮廓、非法落点、绕障路线、十条门线的大步和反向/侧向判定。`npm run test:wayfinding` 用真实浏览器分别检查桌面和手机触屏的十条连接、导航取消与暂停、不可走点反馈、地面引导及路径。另以主线通关和行走动画脚本检查回归。

这是现有 2D 场景的行走可读性改进；角色行走仍采用三方向四帧素材。后续可继续增加转身与步态帧，不把导航改进视为动画素材升级。
