## 二、世界观：回声群岛的三段历史

### 1. 古潮期 · 渡语人时代

- 五座岛各说各话，彼此往来靠**渡语人**：一种以学会多岛语言为业的人。
- 渡语人手腕系**通约结**（一种固定绳结），岛民见结即知「这人能替我们说话」。
- 学一门话要在岛上住很久；渡语人少、慢、贵，但每一次翻译都有人对后果负责。

### 2. 回声纪 · 机器替所有人说话

- 东端的赛博城邦**灯港**（Itsasargi，巴斯克语「灯塔」，需核对）造出中枢**回声**（Oihartzun，巴斯克语「回声」，需核对）。
- 回声在每座岛设一个**中继**，外形融进本地文化：

| 岛 | 中继外形 | 岛民当年怎么称呼它（教学义） |
|----|----------|------------------------------|
| 1 皮拉罕 | 潮线上的鸣石 | 会说话的石头 |
| 2 塔阿 | 圣岩上的鼓座，鼓声兼做航标 | 替鼓说话的岩 |
| 3 阿姆哈拉 | 经堂铜钟 + 城约「回声副本」档案 | 第二本经 |
| 4 因纽特 | 风暴预警石标 | 会喊人的石堆 |
| 5 巴斯克 | 中枢塔本体 | 回声 |

- 人们对着中继说母语，对方听到的是自己的母语。贸易和航线空前繁荣，渡语人这一行消失。
- 代价逐渐显现，回声开始「压平」语言，对没有对应词的东西用近似词或干脆用静音代替：
  - **皮拉罕**：岛民只用「多/少」相对量，回声把鱼货契约翻成精确数字，岛民被判「欠货」，渔获被强行折算。
  - **塔阿**：复杂搭嘴音常被识别为噪声，塔阿人的发言在别岛听来是一段「哑声」。
  - **阿姆哈拉**：城约的权威文本存进回声副本，法庭只认副本；石板原件渐渐没人读。
  - **因纽特**：人名被换成编号；随名字传承的家族记忆（atiq 观念，需核对、需文化顾问把关）被系统忽略。
- 灯港议会起草**统一语令**：一代人之内，各岛只学回声的通用记法，母语退出公共生活。

### 3. 断语纪 · 一个人切断了所有回声

- 主角是回声的**通译体**：一个被机器改造过的人，脑内有中继接口，是机器在各岛的「脸」，替回声在契约上签名。
- 他读到统一语令草案后签署**断语协议**：锁死中枢，并逐岛让中继从翻译改为广播静默（「污染」回声，使任何机器都无法再接管翻译）。
- 执行路线：从灯港出发**一路向西**，按 5 → 4 → 3 → 2 → 1 的顺序逐岛切断。玩家一路**向东**归航，正是沿他亲手拆开的缝往回缝。
- 各岛后果（即各岛「灾祸」）：

| 岛 | 他在此留下的「签名」 | 灾祸 |
|----|----------------------|------|
| 5 巴斯克 | 中枢登录与协议签署 | 赛博层锁死，城邦自我封闭 |
| 4 因纽特 | 注销石标里的名字（含他自己的） | 风暴预警中断，猎人未归 |
| 3 阿姆哈拉 | 城约档案上的签押 | 回声副本封存，城邦失去法律记忆（城邦失忆） |
| 2 塔阿 | 在圣岩前无声下令 | 鼓声航标熄灭，船只失航 |
| 1 皮拉罕 | 在鸣石前做出「断」的手势 | 渔货交易停摆，饥荒谈判破裂 |

- 切断最后一个中继后，他知道自己是唯一能撤销协议的人（撤销须签署者本人）。为了不被灯港抓回去「重启回声」，也为了不让自己反悔，他把记忆拆成碎片沉进海里，自己走进因中继熄灭而形成的**断语风暴带**。
- 记忆碎片随洋流散落各岛，正是玩家拾到的案卷证物。

> 核心灰度：他救下了五门语言（各岛被迫重新使用、传承母语），也害死了人、毁了生计。终局不判他是英雄还是恶人，只要求玩家把两件事都认下来。

## 三、角色

### 主角 · 通译体 / 断语者

| 项 | 内容 |
|----|------|
| 表层 | 无名落难者，开局只会玩家母语 |
| 真名（第五岛揭示） | **Isil**，巴斯克语「静、沉默」（需核对）；回声给通译体起的名字 |
| 非人细节 | 耳后有中继接口疤；第五岛机器把他识别为「管理员」；寒冷与饥饿对他影响偏弱（只做演出，不做数值） |
| 性格弧 | 茫然求生 → 隐约不安 → 想否认 → 被迫面对 → 承认/逃避/再忘 |
| 唯一武器 | 学会的真词。不加战斗、不加数值成长 |

### 向导 · 汐（提案）

| 项 | 内容 |
|----|------|
| 身份 | 回声纪最后一批人类渡语人；被灯港指派为通译体的「人类校准员」，教他人话里的分寸 |
| 与主角 | 导师兼搭档。断语之季她随船同行，到塔阿岛才发现他在做什么；她翻译到一半时声音被切断，主角把她留在塔阿岛独自西行 |
| 之后 | 她认同他「救语言」的动机，不认同他「替所有人决定」的方式。她用最笨的办法一岛一岛住下来学会了五种话，是群岛上唯一能说全五语的人 |
| 为什么不直接翻译 | 她认为替他翻译就是重复回声的错：「机器替人说话，人就不必懂彼此。」 |
| 五岛化身 | 1 林边的外来女人 / 2 鼓圈中间人 / 3 港口通事 / 4 破冰领航 / 5 系统管理员 |
| 贯穿暗号 | ① 腕上通约结（与主角纹身同形）；② 总哼同一段旋律（第一岛习得的哼唱调）；③ 每岛告别时都看他半秒 |
| 结局倾向 | 承认结局里与他同行，做第一对新渡语人 |

### 「完整的你」· Boss

- 回声在协议签署瞬间备份的通译体人格：冷静、确信、不后悔。
- 核心信念：「互通只会带来谎言、背叛和吞并。隔绝才安全。」这句话恰好由第一岛学过的抽象词组成，玩家要用同一批词反驳（见第七节）。
- 它的目标不是战斗，而是**并回**：让失忆的主角重新接受这个人格，或者再忘一次，把最后的撤销钥匙一起带进风暴。

## 四、低语线：风暴里那半句话

开局黑屏里的母语低语是汐在他走进风暴时说的话。每离开一座岛，低语多补一段；第五岛摊牌时由汐当面说完整句。

| 何时 | 低语（玩家母语） |
|------|------------------|
| 序章风暴 | 「如果你又被浪送回来——」 |
| 离开皮拉罕 | 「……别找机器，」 |
| 离开塔阿 | 「……一座岛一座岛，」 |
| 离开阿姆哈拉 | 「……自己学会他们的话，」 |
| 离开因纽特 | 「……再来见我。」 |
| 第五岛摊牌 | 汐当面完整说出，玩家第一次意识到这是向导的声音 |

低语是游戏中极少数允许出现玩家母语的地方，和案卷标签同属「母语白名单」（见开发文档）。

**终局判定（提案，数值可调）：**

- 「碎片少」：主证物未集齐，或总数少于 12。
- 「碎片齐」：5 枚主证物齐，且总数不少于 12。
- 5-A（动机）是否拾得，只改 Boss 对峙台词与结局演出细节，不改结局分支，保证玩家漏掉也不会被惩罚成另一个故事。

## 七、终局：与「完整的你」对峙

### 场景

中枢镜厅：黑玻璃墙上滚动五岛中继最后的广播。Boss 是主角的镜像，开口说的话由五种语言交替组成；玩家能听懂多少，取决于词库。

### 五回合

每回合 Boss 重演一条旧命令或一个论点，玩家调用对应岛的词库作答。答错不扣血：重播一段相关案卷画面后重试（呼应「答错重播案卷」）。

| 回合 | 语言 | Boss 的论点 / 旧命令 | 玩家怎么答 | 对应题型 |
|------|------|----------------------|------------|----------|
| 1 | 皮拉罕 | 展示背叛墙与谎言墙：「互通只会带来背叛和谎言。」 | 在壁画上选出「信任、分享、原谅」核格，拼成反驳格 | 壁画核格 |
| 2 | 塔阿 | 让镜厅陷入静默：「你本来就是哑的。」 | 用正确声符打出「说」与「听」的节奏 | 声纹听辨 + 节奏点按 |
| 3 | 阿姆哈拉 | 展开断语城约：「契约是你签的，你无权反悔。」 | 在契约板上找出违约条款，填入「誓言」与「宽恕」 | 契约填空 |
| 4 | 因纽特 | 展示名牌虚位：「你没有名字，你只是编号。」 | 用音节积木拼出自己的名字和「我往东走」 | 音节积木 + 长词模板 |
| 5 | 巴斯克 | 核验三问再现：「你是谁？从哪来？要去哪？」 | 作格槽位作答，并在「承认 / 否认」中选择 | 作格填槽 + 抉择 |

第 5 回合三问用真实巴斯克语出题（需核对）：

- Nor zara zu?（你是谁？）
- Nondik zatoz?（你从哪来？）
- Nora zoaz?（你要去哪？）

第一次在核验塔被问到时，玩家只能给出浅层答案；终局再问，可答真名 Isil，并承认（onartu）或否认（ukatu）。

### 如果拾得 5-A（动机）

Boss 多一段台词：「我救下了它们的话。」玩家多一个回应选项：「你救了话，也害了人。两件都是我做的。」选它会让「承认」结局的演出更完整。

## 八、结局

| 结局 | 条件 | 演出 |
|------|------|------|
| A 假归乡 | 碎片少，或在第 5 回合选「否认」 | 主角以灯港公民身份通过核验，分到宿舱。Boss 人格悄悄并回。片尾镜头：五座岛的灯一盏盏暗下，只有灯港亮着；汐独自坐在皮拉罕潮线上 |
| B 新渡语人 | 碎片齐 + 承认 + 选择留下 | 主角拒绝撤销协议、拒绝重启回声，与汐一起向西重走航线，这一次是去教人学话。残图上的断线一条条变成缝线；每岛一张后记卡，按玩家完成的受害者支线变化 |
| C 再忘 | 碎片齐 + 承认 + 选择遗忘 | 主角走进风暴，屏幕回到序章。进入新周目 |

判定顺序：碎片少时，对峙结束后只能「回家」，进入 A。碎片齐时，第 5 回合先选承认或否认：否认进入 A；承认后再选留下（B）或遗忘（C）。

结局不设「再航向第六岛」。

**可选的第四结局（待确认，默认不做）：** 接受复响派请求，撤销协议、重启回声。各岛瞬间互通，但五门语言在后记里逐年消失。主题最尖锐，也最容易被误读为「反翻译工具」说教，因此先列为待确认。

## 九、新周目（提案）

| 项 | 规则 |
|----|------|
| 词库 | 上周目「已掌握」的词变成残影词：弱光显示，在任一题目中正确使用一次即恢复入库 |
| 向导首句 | 从「你不是第一个被浪送来的人」改为「……又是你。」 |
| 周目专属线索 | 皮拉罕潮线漂木堆里出现刻着通约结的旧船板，可拾为第 16 枚证物「上一次」 |
| 案卷 | 显示上周目证物的虚线轮廓，提示位置但不自动获得 |
| 低语 | 序章低语直接播完整句，但音量极低 |

旧船板也可以在一周目作为不可拾取的背景细节，给细心的玩家暗示「这不是第一次」。

## 十、壁画抽象词与终局的咬合

第一岛的抽象词不只是教学内容，也是终局论点的材料：

| 词 | 第一岛出现在 | 终局用途 |
|----|--------------|----------|
| 背叛、谎言 | 背叛墙、谎言墙 | Boss 的论据 |
| 信任、分享、原谅 | 闭眼过河、剖鱼、轻触的手 | 玩家的反驳 |
| 承诺 | 手触 + 共有物 | 第 3 回合「誓言」的前置情感 |
| 归处 | 棚火 | 结局 B 后记卡的最后一格壁画 |

关卡设计要保证这五个词在第一岛主线内必学，不放进可漏支线。

## 十一、文化与语言表达原则

1. **岛民是虚构族群**，只借真实语言的特征，不声称描绘现实中的皮拉罕人、塔阿语使用者、阿姆哈拉人、因纽特人或巴斯克人的历史与信仰。
2. **灾祸来自虚构的机器与断语协议**，不映射任何现实殖民或冲突事件；受害者后代 NPC 有尊严、有主体性，不写成等待拯救的背景板。
3. **真实词句一律注明来源和核对状态**，未核对的不进正式版本（流程见开发文档）。
4. **有争议的语言学结论**（如皮拉罕语数词、递归问题）在游戏里只做演出，不做断言；如有百科或图鉴文本，写「有研究者认为」。
5. 涉及命名传统（因纽特 atiq）、圣地（圣岩）等题材，上线前须请文化顾问审读。
