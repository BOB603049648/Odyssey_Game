# 《巴别塔圣歌》调研

> Chants of Sennaar：五层高塔、五种虚构文字、笔记本破译与跨族翻译。不是「一关一个真实单词」的课。

## 它是什么

| 项 | 内容 |
|----|------|
| 中文名 | 巴别塔圣歌 |
| 英文名 | Chants of Sennaar |
| 类型 | 单人解谜冒险（探索 + 破译文字） |
| 开发 / 发行 | Rundisc / Focus Entertainment |
| 发行 | 2023-09-05（PC/主机）；手机约 2025-08 |
| 通关时长 | HowLongToBeat 约主线 9h / 全成就约 10h |

玩家扮演旅人，攀登一座巴别塔式高塔。塔内各族因猜忌不再往来；你要观察场景与对话、破译五种虚构文字，再用翻译修复各族联系。

## 「关」怎么算

**没有「第 N 关学一个真单词」的编号。** 官方结构是一座塔的五层（外加塔顶结局流程），每层一个民族、一套文字。Steam 社区常把笔记本按「五章」对应这五层。

1. 第 1 层：修院 / 隐修院（Abbey）— 信徒 Devotees
2. 第 2 层：城堡 / 要塞（Fortress）— 战士 Warriors
3. 第 3 层：妙园 / 花园（Gardens）— 诗人 / 吟游诗人 Bards
4. 第 4 层：工厂 / 画廊实验室（Factory / Galleries）— 炼金术师 Alchemists
5. 第 5 层：放逐之地（Exile）— 隐士 Anchorites

每层内部还有大量子谜题与区域，但「学语言」的主单位是这五套文字，不是几十个独立「单词关」。

## 五层与五种语言

五种都是游戏内虚构的表意符号系统，不是真实世界语言。字形数量来自评测归纳：

| 层 | 民族 / 地点 | 约字数 | 语法要点 |
|----|-------------|--------|----------|
| 1 | 信徒 · 修院 | 34 | 主谓宾；复数靠重复同一词 |
| 2 | 战士 · 城堡 | 36 | 主谓宾；复数标记在名词前；几乎不用人称代词 |
| 3 | 诗人 · 妙园 | 42 | 宾主谓；复数标记在名词后；否定包在句首句尾；可表疑问 |
| 4 | 炼金术师 · 工厂 | 41 | 主谓宾；复数多在名词后；引入 0–9 数字 |
| 5 | 隐士 · 放逐 | 32 | 主谓宾；字形叠加造字；破译方式与前四层不同 |

## 核心功能点

| 功能 | 说明 |
|------|------|
| 第三人称探索 | 点选交互 / 手柄移动，在开放层内找字、找人、解机关 |
| 笔记本（Journal） | 遇到字形自动入库；可手写猜测义；五族书签分页 |
| 图画验证 | 验证页给插图，把正确字形拖到图上；整页全对才正式解锁含义 |
| 观察破译 | 告示、壁画、雕像、NPC 对话与机关状态对照 |
| 文字相关谜题 | 读懂标牌/指令才能操作 |
| 非文字谜题 | 推车华容道、装备穿搭、水闸等 |
| 潜行 / 变装 / 追逐 | 城堡躲卫兵；工厂怕光；真结局前动作段 |
| 终端 · 快旅 | 全塔约 10 个终端，需手动激活后互传 |
| 终端 · 跨语翻译 | 当口译重建各族对话 |
| 紫门 / 双结局 | 用已学语言开特殊门；条件齐才真结局 |

**核心循环：** 探索 → 发现并记录字形 → 猜测并图画验证 → 用已破译文字解谜 → 解锁新区域；后期叠加终端翻译。

## 和「学真语言」的差别

- 学的是虚构字形与简化语法，不是现实语言课程
- 单位是「一层一套语言 + 多谜题」，不是「一关一个真词」
- 乐趣来自侦探式归纳与验证，不是 SRS / 每日打卡
- 终局目标是修复各族沟通，而不只是背完词表

**对产品的提醒：** 可借鉴观察→猜测→验证的心流、语法差异与跨语翻译；不宜复用其塔名/圣歌名，也不宜误读成多邻国式单词关。
