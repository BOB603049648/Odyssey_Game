# Odyssey v0.1.6

可独立部署的单机浏览器游戏首章：序章 + 东巴岛六个场景。后续岛屿尚未开放。本版不需要后端、账号、数据库或外部素材服务。

## v0.1.6 雾径推理

- 雾径由单次点「停下」改为观察桥板、扶绳，理解刻符，向同行者示意并实际退回前坪的短谜题。新增与原场景风格一致的桥边近景，图片失败可重试，仍保留可操作文字。
- 等待可在桥边通过情景辨认学到；无需为这一个字返回石壁，也不直接解锁整个抽象层。按推荐主线共学 19 字；原有 28 字收集与复用保留。
- 危险＋等待、危险＋已学的保护都能表达有效打算。错误判断有对应反馈，组合可以清空、修改；观察和未提交的组合随存档保留。
- 示意后向导先望向来路，再实际退回左侧路口内侧；玩家穿过返回前坪的门线才完成避险。旧版本已完成避险的存档无需重做。
- 观察、选符、误解、学字、向导回应、完成经历接入已有声音。近景冻结移动与自动帮助，适配手机旋屏与固定关闭入口。
- 具体操作、恢复规则和验收见 `docs/design/v0.1.6-bridge-reasoning.md`；发布包附 `BRIDGE-REASONING.md`，浏览器专项为 `npm run test:bridge`。

## v0.1.5 学习与探索

- 石壁根据当前旅程推荐一枚满足现有解锁条件的刻符；选推荐仍须自行看图作答。当前知识足够时提示「回到旅途」，无需先读完当前层。按推荐路径用 18 个字可走完主线，其余 10 个字保留自由探索；原有通关条件不变。
- 词库可点开已学刻符，重看对应情景画、描述及记忆状态。默认不打开中文教学义；图片失败时仍有情景文字，手机横竖屏均可查阅。
- 自动帮助只在真正闲置 20 秒后给一次观察提示，不再定时升级。实际移动、按键和触屏操作计入活动；加载、菜单、分食近景、后台和失焦暂停计时，主动求助保留。
- 具体方案、推荐流程与后续优先级见 `docs/design/v0.1.5-exploration-learning.md`，发布包附 `LEARNING-JOURNEY.md`。`npm run test:learning` 检查从新存档到离岛的 18 字主线、触屏学习／词库、旋屏及真实闲置帮助。

## v0.1.4 路线与出口

- 路口采用有限宽度与朝向判定；只有从内侧沿出口方向跨过门线才切换场景，沿墙行走或从侧面擦过不会误触发。大步跨门也不会漏检。
- 「路线」面板预览真实可走地面，可固定显示。选定目的地后显示完整绕障路线，先到路口内侧，再跨门；方向键、摇杆与重新点地面可改向。
- 海水、墙壁、桌案和桥外的点击不再吸附到远处地面；停止当前路线并显示原因。出口方向与目的地常驻可见，靠近时提示将去哪里。
- 补齐夜营绕过桌案、火塘的寻路节点。导航提示和剧情对白按实际高度排布，手机与横屏分别适配；旋屏时同步重算镜头，修复灰边及暂停旋屏后人物留在画面外的问题。
- 验收方案与十条连接见 `docs/design/v0.1.4-wayfinding.md`；可运行 `npm run test:wayfinding` 复验。

## v0.1.3 操作与场景变化

- 雾岸取水：拿起空瓢，在潮水与泉嘴间观察尝试，理解“水”后接满，再饮用。接水不会直接完成饮水；错误尝试不消耗道具。
- 前坪分食：查看、拿取四份食物，进入双碗近景亲手移动与移回，理解分享／给予后将两份晚餐递出。总量守恒，可中途离开；阶段与分配随存档保存。旧版本已完成水／食物目标的存档不必重做。
- 新增旅人站坐／起身八帧、向导观察／抬爪／坐卧八帧。动作使用统一有效时间，菜单与后台冻结、重复操作重置、移动打断；物件接触帧驱动声音。
- 拿走的瓢与食物篮会改变画面，分食后留有餐食；局部泉水、火光、余烬与窗尘增加环境活动。状态贴片依据原图生成，只替换标定区域，保持原有构图与脚点。
- 旅人动作与场景状态图纳入首屏解码和重试；向导新姿势预加载，失败时沿用完整立绘。制作源保留，角色运行时采用无损 WebP。具体操作与验收见 `docs/design/v0.1.3-playable-world-plan.md`。

## v0.1.2 声音体验

- 52 段内置 MP3，音频合计约 4.8 MB。录音使用已核实 CC0 素材，来源、作者、原件哈希和复现脚本随仓库保存；发布包附 AUDIO-CREDITS.md。
- 沙地、石地、木地板三种脚步，共 16 个真实录音变体，跟随显示中的落脚帧；衣料、取水时的液体晃动、饮水、放下容器、坐下、拿取和纸张音对应动作或事件。
- 刻符选择、答对、答错、学会新字和首次完成生存经历各有短音。猫呼噜保留给漂木相遇，主动请求帮助时可听到猫叫。加载/恢复存档不会重放奖励。
- 雾岸、前坪、棚火、雾径、夜营采用 48 秒环境声；前坪不再直接复用海岸。棚火采用真实火声，夜营有虫鸣；鸟声、木声间歇出现并有轻微声像变化。
- 标题、回忆和首章完成有三段共享旋律动机的原创合成配乐；探索保留环境与动作声音。首次标题需点击“启用声音”后才能播放；尊重浏览器自动播放限制。
- 总音量、动作与反馈、环境、音乐独立调节并持久保存。暂停、菜单、停止移动和换场景会清理相应声音；迟到的脚步不补播。解码缓存限制为 48 MiB，正在播放的声音独立保有其缓冲区。

## v0.1.1 修复

- 声音：未解锁时显示“启用声音”；音量为零时显示“声音关”。恢复声音会恢复可听音量，拖高滑条会解除静音；主动静音仍保留到下一次游玩。
- 从后台、系统音频中断或浏览器暂停恢复时重新启用现有音频；若自动恢复被浏览器拦截，下次游戏操作或“启用声音”可重试。支持 Audio Session 的浏览器请求 playback 路由。
- 标题和设置增加“试听声音”，播放不依赖 MP3 下载的两声提示音。场景音频失败会显示重试入口。
- 行走：同一图集固定图片 URL，只变裁剪坐标；切入待机或交互图集时隔离原生图片节点，防止旧图片套上新缩放。位置更新短暂落后时保持当前行走帧，松键立即停，碰壁后停步。

## 本版体验

- 四幕横竖屏序章：局部关节运动、雨浪与光效、同步音景，支持暂停、重播、连播、跳过和减少动态效果；WebGL 不可用时保留完整静态画面。
- 统一绘制潮线、棚火、前坪、经堂、雾径和夜营；互动位置对应画面，角色留在可走地面和栈道上。
- 三方向四帧行走、各四帧伸手与饮水、四帧坐下和四帧起身；动作随交互触发，移动打断，低帧率下保持正确时长。
- 28 个字的辨认与应用，饮水、食物、休息、避险四项主线经历，三条可选线索，离岛回忆与首章完成页；完成后可继续探索、复习。
- 六个场景的环境音、猫叫与呼噜，统一音量和静音，切页停止旧声音，失败不阻断游戏。
- 自动存档、JSON 备份/恢复、无效文件校验、恢复前预览确认、重新开始确认；设置页提供操作说明。

## 部署到阿里云 /test/

既有约定：代码推到修复分支，由用户或 Grok 执行部署。此仓库不包含阿里云 SSH 凭据，也不会自动覆盖服务器。

1. 拉取 PR #66 的最新 `fix/snapshot-portability-and-gameplay`，核对提交；用 Node 22+ 执行 `npm ci`、`npm test`、`npm run content:check`。
2. `npm run release:pack` 从干净提交重新构建，在 `artifacts/releases/` 生成 ZIP 与 SHA-256。也可以直接使用交付的 ZIP，验证旁边的 `.sha256` 后解压。
3. 将包内 `index.html`、`assets/`、`version.json` 等内容放到同一个临时站点目录，验证后原子切换到 `/test/`。不要只覆盖 HTML 或只覆盖 assets；保留前一版目录便于回滚。
4. `index.html`、`version.json` 使用 `Cache-Control: no-cache`；带哈希的 assets 可使用一年 immutable 缓存。缺失的 `/test/assets/*` 必须返回 404，不能回退到 index.html。
5. 打开 `http://47.252.94.138/test/version.json`，确认 `version` 为 `0.1.6`、`revision` 是所部署提交、`dirty` 为 `false`；再用无痕窗口验收。

Vite 使用相对资源路径，同一个包可部署到 `/` 或 `/test/`。无需专门为目录重建。存档按浏览器和域名/端口保存；更换域名、端口或 HTTP/HTTPS 前请备份。建议正式发布使用 HTTPS。

## 部署验收

- 新游戏播放/暂停/跳过序章；确认横屏和手机竖屏人物完整。
- 六个场景无资源 404、无永久加载遮罩；到达物品后点击或按 E 可互动。
- 主线：拿起空瓢 → 壁画学字 → 接水饮用 → 营地休息 → 前坪分食并递出 → 雾径观察、用刻符示意并返回前坪 → 回岸离岛 → 回忆 → 首章完成；可继续岛上探索。
- 石壁只学当前需要的刻符即可返回，推荐不跳过锁定或自动作答；词库能点选情景画，继续学习其他词和复用仍可使用。
- 按住方向键或摇杆时不冒出自动提示；停止操作后只给一次观察提示，主动求助仍有效。
- 雾径近景的桥板、扶绳可观察，等待可以现场辨认；错误组合可修改，示意后向导会返回。此时避险仍未完成，实际走回前坪才完成；中途刷新保留观察与组合。
- 手机摇杆与路线菜单能往返所有场景；打开菜单时角色停止移动。路线面板显示可走范围，固定后可保留；选出口后出现实际路线，靠近正确路口才切换。
- 点击海水、墙壁、桥外时停止并提示；沿营地北墙远离中央路口行走不误入夜营。键盘与摇杆可以随时取消自动导航。
- 刷新后继续；导出存档、导入预览并恢复；取消新游戏保留原进度。
- 标题或设置点“试听声音”，应听到两声提示音；序章和岛上应有环境音。静音重载后仍静音；调大音量可恢复。
- 切至后台再返回，声音自动恢复或可点“启用声音”恢复；音频文件失败时出现重试入口，仍可继续游戏。
- 持续走动、转向、走停切换、饮水和休息时，人物不应突然放大或短暂变成其他帧；落脚、饮水、坐下的声音与动作同步。
- 按住方向键碰壁、停止移动、打开菜单后没有残留脚步；延迟加载的声音不应在停步后集中播放。
- 单独关闭音乐，环境与动作音效仍可播放；分项音量刷新后保留。
- 取瓢后原位为空；错误水源不丢杯，接水后刷新仍持有清水；喝下后目标才完成、瓢归位。
- 分食近景可以在两碗间反复移动，四份总量不变；不均分不能递交，均分后完成。部分分配刷新仍保留，老完成存档直接显示完成结果。
- 饮水或坐下中途开菜单、切后台，回来后从原动作阶段继续；向导的观察、提示与坐卧可以区分。

自动检查：`npm test`、`npm run content:check`、`npm run build`。浏览器检查需先在 4173 启动 preview，再运行 `test:bridge`、`test:learning`、`test:wayfinding`、`test:puzzles`、`test:performance`、`test:browser`、`test:controls`、`test:movement`、`test:gameplay`、`test:experience`、`test:prologue`、`test:cinematic`、`test:release`、`test:audio`、`test:foley`。可通过 `CHROMIUM_PATH` 指向已有 Chromium，或 `npx playwright install chromium` 安装。

## 发布边界

v0.1 是首章试玩版；后续四岛、完整游戏结局、真人配音和云存档不在本版内容中。画面采用 2D 绘景与局部关节动画，非 3D 骨骼动画。浏览器自动化覆盖 Chromium 桌面与触屏尺寸；真实 iOS Safari 和低端安卓仍建议上线前进行设备抽查。现有存档会沿用，不强制清档。
