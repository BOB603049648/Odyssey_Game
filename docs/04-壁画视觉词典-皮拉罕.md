# 壁画视觉词典 · 皮拉罕岛

> 《奥德赛》第一岛壁画词典：从太阳月亮等具体词教到抽象词；含交互、解锁、案卷罪证钩子与完整词表。

## 机制一句话

**壁画视觉词典：** 岩壁壁画是无母语标签的图解词典。玩家凝视、点选画面、与实物或 NPC 动作对照；猜对后入库。抽象词不画孤立符号，而用已学会的具体词拼成场景句子。

## 设计约束

- 皮拉罕语偏即时经验、数词极弱：词表优先生存与可见动作；抽象义用场景演出来
- 壁画：线刻与矿物色、剪影人物、日月亮水火鱼重复母题
- 教学 HUD 不用母语；母语只出现在案卷证物标签

## 教学流程

1. **第0层 指物** — 日、月、水、火、鱼、人：壁画旁有实物；点壁画高亮并点实物，配对入库。
2. **第1层 动作** — 吃、喝、睡、走、给、拿：两格前后画面；对 NPC 做对动作验证。
3. **第2层 关系** — 我、你、大小、多少（相对量）、危险：对比构图。
4. **第3层 抽象** — 饥饿、承诺、背叛、信任等：由已解锁元素拼多格叙事；缺词则格模糊。
5. **第4层 复用检验** — 第二面墙换角色重画；再点对核格才算掌握。

原则：抽象等于具体词的句法。学的是看懂场面。

## 抽象词壁画示例

| 教学义 | 壁画怎么演 | 核格（要点哪里） |
|--------|------------|------------------|
| 饥饿 | 人按空腹，望向鱼，步伐虚；旁格对照完整的吃 | 按腹那一格 |
| 承诺 | 两人伸手相触，中间放下去水囊，走开仍回头 | 相触的手与留下的物 |
| 背叛 | 同承诺构图，一人背身拿走共有物，第三人跌倒 | 背身取物者 |
| 信任 | 一人闭眼，另一人引路过河，无绑无刀 | 闭眼者与引路的手 |
| 危险 | 警示纹加人止步，旁有兽影或裂岸 | 止步姿态 |
| 分享 | 一条鱼剖成两半，两人同时伸手 | 对半分的鱼 |
| 等待 | 人坐岸边，墙上重复盖多个日轮小印 | 日轮印串 |
| 想念 | 两人身影隔水，对岸人变成虚线轮廓 | 虚线轮廓 |
| 原谅 | 背叛续格：取物者放下物，两人再次轻触手 | 轻触的手 |
| 谎言 | 一人指向有鱼的方向，邻格河空无鱼，嘴旁短折线 | 空河与嘴旁折线 |
| 保护 | 大人影罩住小人影，外侧有兽 | 罩住的弧影 |
| 归处 | 脚印从林回到棚火，棚上有睡姿小印 | 棚火 |

每词固定一到两处核格可点；点错只轻抖，不扣血。

## 交互与进度解锁

| 交互 | 说明 |
|------|------|
| 靠近 | 进触发区，可点热区出现，先不显示词义 |
| 凝视触摸 | 长按核格放大；左右滑看多格；再长按尝试入库 |
| 对照 | 身上有相关实物或刚做对动作时，亲缘热区亮起降难度 |
| 反复查看 | 已学会词呈弱光轮廓；依赖未齐时抽象格保持模糊 |
| 解锁新层 | 词库达标或主线节拍后，揭苔藓或加颜料层露出下一带 |
| 复用检验 | 第二面墙或夜景版打乱位置，要求再点核格；须在没有奈奈茶三级提示的情况下通过 |
| 奈奈茶提示 | 卡住时她转头看相关格（一级）、走到墙边用尾巴指（二级）、用爪拍核格（三级）；玩家也可点她请求提示 |

解锁门槛：

1. 具体词至少6个后，开放动作层
2. 动作词至少4个后，开放关系层
3. 关系词齐后，开放抽象叙事带，老人可带你夜读旧层

## 与案卷碎片呼应

- 罪证画进壁画多出来的一笔：学到特定词后才可被点选
- 背叛墙：取物者腕上绳结纹身与主角相同；点中写入案卷
- 等待墙：日轮印重叠处浮现残缺人脸，像玩家
- 奈奈茶夜里守着的旧层：用已学词读完场面，才掉第一岛主碎片
- 「信任」墙（闭眼者被引路过河）与奈奈茶引路的关系是伏笔，终局会被重画成一只猫领着闭眼的人
- 罪证热区不标母语；可漏掉（影响终局），不卡学词主线

## 验收清单

- 不看母语，仅凭壁画与实物能完成指物到关系层至少10词
- 依赖词未齐时抽象墙明显学不会
- 至少12个抽象相关义有核格，并有复用检验墙
- 至少1处罪证热区依赖已学词，漏掉不卡主线
- 夜读旧层（离岛前主碎片）条件：抽象层至少含饥饿、承诺、危险
- 奈奈茶的提示只用动作和眼神，不出现母语
