# 故事纲要 · 奥德赛

> 《奥德赛》：风暴落难、学真语言向东归航；记忆碎片是罪证，拼图越全越接近真相——你才是最后的大 Boss。

## 一句话

**作品名：奥德赛。** 你以为自己是风暴里落水的旅人，靠学真语言一路向东回家。其实你不是纯粹的人：群岛上的灾祸与你有关。每捡一块「记忆碎片」不是奖励，是罪证——拼得越全，越清楚自己是谁。终点等着的大 Boss，是你自己。

## 主角背景

| 项 | 内容 |
|----|------|
| 表层身份 | 失忆落难者；开局只会母语，岛上人人听不懂 |
| 真实身份（终局揭示） | 回声群岛旧秩序的「断语者」：曾切断/污染各族互通；风暴是自我放逐或被放逐的余波 |
| 做过什么 | 各岛灾祸同源——饥荒谈判破裂、航线消失、城邦失忆、赛博层锁死……碎片逐条对上他的决定 |
| 为什么落难 | 表层：暴风雨翻船。深层：逃开后果，或记忆被拆碎扔进浪里 |
| 非纯粹的人 | 可保留一点非人设定；玩法上仍用「学词」当唯一武器 |
| 细化 | 原是渡语人，后被中枢改造为「通译体」，记忆被压平；签署断语协议后从东往西逐岛切断中继，再把记忆拆碎沉海。无真名可找回，终局揭示的是「断语者」身份。详见 [主线剧本与世界观](05-主线剧本与世界观.md) |

## 世界设定

海域「回声群岛」：每座岛对应一门与玩家母语距离很远的真实语言。学到的是真词真句。双生地图 = 景物 ↔ 词库 ↔ 航线亮点。

群岛彼此听不懂，是主角当年「断语」留下的疤。向东「回家」，其实是在沿他亲手拆开的缝往回缝。

历史分三段（详见 [主线剧本与世界观](05-主线剧本与世界观.md)）：

1. **古潮期** — 靠人类「渡语人」往来，慢而有人担责。
2. **互通纪** — 东端霓虹港的中枢在各岛设中继，实时互译；语言被逐渐压平，议会起草「统一语令」。
3. **断语纪** — 主角签署断语协议，按 5→4→3→2→1 逐岛切断中继；玩家按 1→5 向东归航，正好逆着他的路线。

## 开局（第一岛）

1. **暴风雨** — 翻船落水；黑屏里一声猫叫，他的手下意识伸了出去。
2. **冲上岸** — 皮拉罕岛：听不懂、要活命；手势与实物当教程。
3. **存活** — 要到水、食物、过夜处；每步猜对关键词才推进。
4. **向导 + 残图** — 一只比人还大的猫咪精灵领他往东，把残缺海图叼到他脚边。临走她回头看他半秒。
5. **第一块罪证** — 潮线捡到第一枚记忆碎片：画面里有他的手在做「断」的手势。

> 向导（示意，无台词）：大猫先领他到漂木堆前坐了一会儿，那里有不止一条旧船的残骸（你不是第一个被浪送来的人）；然后起身朝东走，回头等他。

## 向导：奈奈茶

| 项 | 内容 |
|----|------|
| 表层 | 比人还大的猫咪精灵，只在五座岛上现身引路；每座岛换一种形态（毛色、饰物、体型），脖子上的旧绳圈始终在 |
| 真相 | 主角还是渡语人时收养的流浪猫，名字是他起的；他被中枢压平记忆时把她忘了，她没有忘记他 |
| 暗号 | 脖子上的旧绳圈（他当年随手系的）；一种让他莫名心安的呼噜声；告别时回头看他半秒 |
| 玩法 | 不教语言（交给各岛 NPC）；负责引路，并作为提示系统用动作和眼神示意答案 |
| 主题 | 她不会说任何一门人类语言，却始终听得懂他：不靠翻译中枢也能理解 |
| 结局 | 承认真相才能叫出她的名字；否认就仍把她当陌生的精灵。承认后若重启中枢，这段认识会再次失去 |

## 记忆碎片机制

碎片不是宝箱奖励，是罪证档案。UI 上像裂开的海图残片 / 烧焦录音条；收集进「案卷」而不是「成就柜」。

1. **何时触发** — 每岛主线关键冲突解决后强制或半强制一枚；可选禁地/受害者后代额外掉落。
2. **长什么样** — 短过场无旁白审判；案卷留下证物标签。
3. **怎么收集** — 「拾起 / 听完」；不卖不升级；只改案卷完整度与终局分支。学词仍是主循环。

## 主线弧与 Boss 铺垫

| 岛 | 表层目标 | 罪证钩子 |
|----|----------|----------|
| 1 皮拉罕 | 活命；往东 | 潮线碎片：他的手做「断」；大猫似曾相识 |
| 2 塔阿 | 在搭嘴音声里求通行 | 部落忌讳「外来哑声」；壁画里有他轮廓 |
| 3 阿姆哈拉 | 碑铭城借船 | 经卷点名「断语者」；碎片里他签过城约 |
| 4 因纽特 | 拼几何航图 | 音节字通缉令——画像越来越像玩家 |

节奏：1–2 岛只觉「诡异」；3 岛起怀疑英雄叙事；4 岛通缉令让否认变难；5 岛确认。

## 结尾怎么收

1. **反转** — Boss 是完整记忆归位后的「断语者」人格。
2. **对决形式** — 语言对峙：用五岛学过的真词回答/反驳/翻译自己当年的命令。
3. **收束分支**
   - 碎片少：逃回家，群岛依旧隔绝（A 假归乡）；她仍是陌生的精灵
   - 碎片齐 + 否认：同样是 A；他不承认，也就叫不出她的名字
   - 碎片齐 + 承认 + 留下：叫出她的名字，拒绝重启中枢，留下当新的渡语人（B 新渡语人）
   - 碎片齐 + 承认 + 重启：他看见饥荒、失船和失去的法律记忆，相信只有中枢能救人，于是重启中枢（C 重启回声）。语言再次被压平，他自己也再次消失；奈奈茶在霓虹港门口等他，他走过不停，彼此不再认得
   - B 与 C 都有代价，没有标准答案。不设再忘，也不设新周目

## 与玩法怎么咬合

| 故事 | 玩法 |
|------|------|
| 听不懂岛民 | 少给母语翻译；场景/选项/听音猜义 |

| 向东去 | 通关亮航线下一格 |
| 双生地图 | 词库 ↔ 地标；也逐渐显出「断语」裂痕 |

## 刻意不做的

- 不蹭巴别塔/圣歌命名与宗教闭关主轴
- 不做虚构文字冒充真学
- 开局不说明书；风暴与听不懂当教程
- 碎片不当数值奖励；Boss 战不另开无关战斗系统

## 待定

- 断语者具体手段：科技 / 仪式 / 契约（定一种即可）→ **已定：契约**（断语协议，由中枢执行）
- 向导与主角旧关系 → **已定：向导是主角收养的流浪猫奈奈茶**，以猫咪精灵形态引路
- 专名 → **已定：按原剧本**，主角无真名；中枢、霓虹港不另起专名；唯一专名是奈奈茶
- 结局 → **已定：A 假归乡 / B 新渡语人 / C 重启回声**。碎片少或否认进入 A；承认后选留下（B）或重启（C）。B 与 C 都有代价。不做再忘、新周目或残影词
