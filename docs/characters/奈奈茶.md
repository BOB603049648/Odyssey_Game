# 向导角色设定 · 奈奈茶

> 《奥德赛》跨岛向导。画面默认**不显示名字**；**不说话、不教词**；**无恋爱线**。  
> 美术：写实电影感（对齐 `odyssey-art/07-cinematic-keyart.jpg`、`08-cinematic-hud.jpg`）。  
> 玩法：三级提示 **看 → 走 → 拍**；idle 呼吸；注视目标；按节拍换姿势。  
> **造型锚点**：用户真猫照片（暹罗色点 / seal-point），禁止豹纹与耳叶神兽感。

---

## 1. 一句话

被遗忘的流浪家猫变大：沉默的暹罗色点向导，奶油身、巧克力面具与亮蓝眼；旧绳扁结 + **旅行披风**作为跨岛可辨认符号——它记得你，却不揭穿你。

## 2. 外形（第一岛定稿，跨岛同体）

| 项 | 定稿 |
|----|------|
| 体型 | **比人还大的家猫**（肩高过普通成人胸口）；脸身比例=参考真猫放大，不是豹/神兽骨架 |
| 毛色 | **奶油 / 浅焙茶色身** `#E6D4B8`–`#C9B089`；短毛家猫质感 |
| 色点 | **深褐巧克力点**：全脸面具、耳、肢端（袜）、整条尾 `#3B2418`–`#2A1810`；过渡自然，**无斑点/蔷薇斑/豹纹** |
| 耳 | 标准家猫三角耳；**无耳后阔叶、无植被附着** |
| 眼 | **亮天蓝** `#4B9FE0`，杏仁形；idle 半眯，看向目标时睁圆、单点电影高光 |
| 鼻 | 成猫偏深褐 `#2C1C16`；回忆小猫可偏粉 `#E8A8A0` |
| 颈饰 | **旧绳圈**一圈，磨损麻绳色 `#8B7355`；前方一枚**扁结** `#5C4634` 与岛上「背叛」证物绳结同形同编法 |
| 披风 | **主线大猫常穿**：磨损茶褐 / 橄榄灰旅行披风（粗织帆布或油布感）`#6B5B4A`–`#8A7A66`，毛边破洞，骨/木制扣 + 麻绳系；罩肩背，帽兜可垂可不戴——让玩家一眼认出「这只向导」 |
| 爪 / 尾 | 前掌可点触（拍提示）；尾长、深褐实色（非环纹豹尾），领路时尾尖可先指向目标 |
| 体态语言 | 无嘴型对白；情绪全靠耳向、瞳孔、尾、肩峰起伏 |

**禁止**：豹纹、蔷薇斑、耳后宽叶、雨林神兽/神话生物感、多邻国扁平可爱风。

**跨岛同体原则**：五岛（东巴→甲骨→小篆→藏文→西夏）是**同一只奈奈茶**，不换物种。主线大猫**始终披风**（可脏可霜可沙，不换款式），本体比例 / 色点 / 绳结 / 披风剪影不变，保证玩家辨认。

### 2.1 回忆小猫形态

| 项 | 定稿 |
|----|------|
| 身份 | **同一只**奈奈茶的幼年回忆态（闪回 / 旧层），不是另一只猫 |
| 外形 | 同色点更幼：奶油身、巧克力面具/耳/肢/尾、亮蓝眼、短毛；体型为真实小猫比例 |
| 颈饰 | 同一枚**旧绳扁结**（更松、略大相对比例）；**无衣服**（参考照樱桃衣剔除）；**默认不披风**（回忆态更「还是家猫」） |
| 用法 | 夜宿/罪证闪回/序章；主线过场仍用带披风大猫 |

## 3. 性格与禁忌

- **性格**：沉默、耐心、略带审判感；亲近但不撒娇；答对时耳向前、尾慢摆；答错时歪头 + 耳侧倒，不嘲讽。
- **做什么**：用注视、走动、拍触三级提示；节拍换姿势（领路、棚火蜷、叼海图离岛等）。
- **不做什么**：不说话、不弹出词卡教学、不恋爱、不替玩家点选答案、默认 UI 不写出「奈奈茶」三字（开发可用内部 id `nanaicha`）。

## 4. 玩法角色（给开发）

| 等级 | 动作 | 表现 | 触发建议 |
|------|------|------|----------|
| L1 看 | Look | 头+眼转向关卡目标（壁画符/骨片/印面等），尾尖微指 | 犹豫 N 秒 |
| L2 走 | Walk | 起身踱到目标旁，坐下侧身让出交互点 | L1 后仍错/超时 |
| L3 拍 | Tap | 前掌轻拍正确热区（或附近石面），一次一下 | L2 后仍错 |
| Idle | Breath | 胸腔微起伏；耳微动；循环 3–4s | 默认 |
| Wrong | Tilt | 歪头、耳侧、眨眼一次 | 答错反馈 |
| Carry | Hold | 口叼海图/残页等离岛物件 | 离岛节拍 |
| Night | Guard | 棚火旁蜷卧，眼半睁看向「旧层/罪证」方向 | 夜宿/回忆段 |

内部动画状态机建议：`idle | look | walk | tap | tilt | carry | guard`。

## 6. 光影备注（写实电影感）

- 主光：岛岸天光 / 棚火橙（视场景）；体积光与毛发 rim light 细一圈。
- 禁止：扁平色块描边、多邻国式可爱高饱和、眼睛超大二次元高光。
- 毛发：可见短簇与真实暹罗色点过渡，不要塑料光滑，不要豹斑噪声。
- HUD 同框时：角色实、UI 半透明玻璃，参考 `08-cinematic-hud.jpg`。

## 7. Web 分层建议（替换 CatMark SVG）

推荐图层（从后到前），便于 Spine/CSS/Canvas 换装与提示动画：

1. `body` — 躯干+后肢（呼吸缩放枢轴在胸）
2. `tail` — 独立，可摆尾指向
3. `head` — 含耳基与面具
4. `ear_L` / `ear_R` — 可倒耳
5. `eyes` — 或 `eye_L`/`eye_R` + 瞳孔层（注视 IK）；天蓝虹膜
6. `collar_rope` — 绳圈
7. `collar_knot` — **扁结单独一层**（罪证闪回时可微光）
8. `forepaw_L` / `forepaw_R` — 拍提示用
9. `prop` — 可选：海图/残页（carry）
10. `silhouette` — 纯黑剪影 PNG，用于教程镂空/回忆闪回

**已删除**：`leaf_L` / `leaf_R`（耳后阔叶作废）。

## 8. 罪证挂钩（编导用）

颈上扁结 = 各岛「背叛」绳结证物的**同形钥匙**。玩家未拾碎片时只是旧项圈；拾取后闪回里绳结发光/叠化到证物特写。奈奈茶不解释，只在 guard / 罪证节拍看向旧层；回忆小猫可同框强化「同一绳结」。
