# 玩家角色设定 · 旅人

> 《奥德赛》**玩家可控主体**（第三人称略俯斜 2D 探索 avatar）。  
> **不是**向导：向导是帽兜披风大猫「奈奈茶」。  
> 美术：写实电影感。

---

## 1. 一句话

失忆的「断语者」以旅人身份上岸——沉默、疲惫、能走能探；不教词、不解说关卡。

## 2. 外形（正式稿）

| 项 | 定稿 |
|----|------|
| 年龄感 | 约 28–35；东亚男性面容 |
| 发 | 深色微卷，齐肩或及颌，风吹略乱 |
| 服装 | 橄榄灰 / 炭褐短旅行披风（敞篷，与奈奈茶茶褐长披风+帽兜区分）；内层耐磨长衣；臂缠 / 皮护腕；皮带 |
| 装具 | 斜挎旧皮囊；**短杖** |
| 靴 | 沾泥高靴，实用 |
| 气质 | 沉默求生者 / 带罪感的旅人；目光安静不「教学」；不是吉祥物、不是法师特效 |

**与奈奈茶区分**：人 vs 巨猫；短橄榄披风敞篷 vs 茶褐长披风**戴兜**；旅人持短杖，向导用注视/走/拍提示。

## 3. 不做的事

- 不说话教词、不弹出词卡教学、不做恋爱对象
- 不抢向导戏份：提示权威在奈奈茶
