# 奥德赛（Odyssey）

真实语言学习游戏。灵感来自《巴别塔圣歌》的破译心流，学的是真实、远距语言；产品名不蹭巴别/圣歌命名。

当前可玩切片是**序章 + 皮拉罕岛的一截**：标题、契约断语的闪回、遇见不说话的大猫向导、潮线 / 棚火 / 河湾 / 岩壁 / 密林 / 夜营，壁画从具体配对走到动作、关系、抽象和复用，案卷收三枚证物。教学义默认关闭。三条结局的数据是假归乡、新渡语人、重启回声；对峙本身还不能玩。皮拉罕原文仍是待核对占位，词表里不写未审定的拼写。

## 看新节拍

`npm run dev` 后：

1. 新游戏，过完序章，走上潮线。打开案卷，应看到「签署手势」，另外两格是空位。画面上不出现向导的名字。教学义默认关闭，壁画上没有中文释义。
2. 顶栏可以去棚火（躺下）、河湾（递过去）、岩壁（壁画）、密林（停下 / 走进去）、夜营（看旧层）。对应的词还没记下时，这些动作只会摇一下。
3. 潮线或岩壁打开壁画。具体层六格都记下后，第二带才打开；动作记下四格后打开关系层；关系层五格后打开抽象层。记下任意一格后，最右侧复用带可以再点一次，把那一格记熟。
4. 学会「背叛」后，岩壁或壁画上会出现「腕上的结」，案卷多一枚「绳结纹身」。学会饥饿、承诺、危险后，夜营「看旧层」得到「数字的石头」。这两枚都可以不拿。漂木只是坐下，不进案卷。
5. 潮线上先把「水」用出去，并且饥饿、承诺、危险都已记下，再点「往东」。先看到离岛：她把海图角叼来，回头。再点「下一幕」，进入没有字幕的三段回忆（雨、码头下的小猫、斗篷）。回忆不进案卷。之后可以从海图角、夜营的「回忆」，或案卷里的「回忆」再看一遍。
6. 她会按节拍换姿势：先领向漂木，棚火边蜷着，要离岛时叼着海图。点她逐级提示。答错只歪头。开发服务器左下角有「调试」，正式构建里没有。

## 运行

需要 Node.js 20 或更新版本。

```bash
npm install
npm run dev
```

浏览器打开终端给出的本地地址。

```bash
npm test
npm run content:check
npm run build
```

手机壳只放了 `capacitor.config.ts`（`webDir` 为 `dist`，应用名「奥德赛」）。还没有添加 iOS / Android 工程，也不走商店打包。

存档在浏览器 `localStorage`（键 `odyssey.save.v1`）。刷新后从标题选「继续」。
